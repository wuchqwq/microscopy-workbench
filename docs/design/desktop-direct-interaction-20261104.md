# 面向图像的桌面操作合同

本轮以原图 → ROI → FFT → 对照 → 修订 → 明确保存为主线，借鉴成熟软件的直接操作，不另建布局、导航或科学存储体系。

| 动作 | 工作台采用的规则 | 本轮状态 |
| --- | --- | --- |
| 查看与换工具 | 默认选择；左栏选择、平移相邻。V/H 切换，空格临时平移；缩放和平移不改变科学选区。 | 移动已有平移按钮，不新增一排入口。 |
| 切图 | 第一次点击先置顶并经过版本、租约与解码检查激活；后续手势才编辑。正常切窗停放工作草稿。 | 复用现有窗口管理，不绕过保护。 |
| 改 ROI | 框选后回选择；内部移动、控制点缩放；重叠时用现有消歧入口；Delete 只作用于明确选中的图形，文字焦点保留文字编辑语义。 | 已有行为沿用，不引入无选择全删。 |
| 看 FFT 和来源 | 当前选区决定新计算输入；已有结果直接查看。返回计算时原图与返回最新 ROI 分开，旧输入保持自己的历史几何。 | 复用 #118 的准确关系；实时模式由研究者显式开启，规则见本轮更新。 |
| 判断修改 | 未应用字段逐字回到当前有效原值，只清除这一项草稿；真实几何、排队修订、失败或未知操作独立保留。已执行的新科学版本仍需明确保存。 | 修复理由和名称／颜色／状态的假 dirty，保护跨 ROI 与迟到读回。 |
| 应用、保存、导出 | 应用进入工作编辑；Ctrl+S 发布明确保存点；导出另写数据或图片。关闭子窗仅关显示，退出有修改才保存／不保存／取消。 | 保留已确认的整体分析工作区合同，不用内部落盘冒充已保存。 |
| 用窄窗口 | 属性围绕当前选择出现；显示与诊断按需展开。关闭、保存、帮助可达，收起不清字段。结果展开后可明确 Fit，后台刷新不自行重置相机。 | 原生与 DOM 分别验收；未证实的裁切原因不凭猜测改 CSS。 |

这些是本项目的操作合同，不能用别的软件名称代替实际验收。学习重点是少做辅助操作就能看清、选对和返回；科学对象身份、原请求与历史证据继续由现有工作区维护。

参考边界：Gatan 当前 [DigitalMicrograph 产品页](https://www.gatan.com/Products/TEM-Software/DigitalMicrograph-Software)说明工作区、数据布局及按技术组织的工作流，不能证明其未公开的 dirty 算法或首击行为。[ImageJ IJ 1.46r 工具说明](https://imagej.net/ij/docs/guide/146-19.html)和 [napari Shapes](https://napari.org/stable/howtos/layers/shapes.html)可对照选区、控制点、选择与临时平移。1999 年 DM 手册仅作历史参考；本轮没有运行 DM 或宣称最新 GMS 实机行为。

## 需求记录：Live FFT（2026-11-08，已纳入本轮）

用户最初要求先记录，随后明确纳入本轮整体改版实施；以下整批授权与实现约定是当前要求。复用既有 FFT 分析内核，明确窗函数、去均值、源坐标与标定；只在主动开启后节流更新，旧结果保持原输入。打开图像仍只准备显示，不自动分析。

## 本次整批授权更新：Live FFT 与日常画布（2026-11-08）

用户澄清 Live FFT 应随这次完整前端批次实施，而不是继续排除。主动开启后，矩形 ROI 移动或缩放停顿350ms再派发；同一时刻只运行一个既有 FFT，请求冻结原浮点选区、实际整数支持、源图和参数。旧回包不覆盖新选区，未知结果暂停自动更新并保留原请求；“固定此结果”显式进入现有窗口和保存体系。打开图和普通固定FFT不自动开启实时计算。实时预览不作为新的物理标定或科学结论。

日常主界面以图像、ROI和科学命令为中心。文件/导航/适应/关闭采用有可访问名称和悬停说明的图标；数值、历史、来源从结果导航查看；研究问题、内置模型与离线候选保留为次级历史记录入口，不删除旧数据。未选中的ROI名称安静显示；只对选中的FFT显示来源范围。标题附近区分旧选区、原选区与来源未知，固定结果保持不可变，可主动回看来源或重算当前ROI。外部Codex继续通过同一MCP、科学对象与工作区工作，不新增AI计算路径。

## 斑点几何、衍射定标与侧栏（2026-11-08）

左栏默认144px，拖动或方向键可在132–280px间调整，折叠为46px图标栏；按钮保留工具名提示与可访问名称。这是布局偏好，不修改科学对象。

FFT 点测量复用既有固定数学 DC、频率坐标和原图实空间 XY 标定；不允许重新指定 FFT 中心。电子衍射标量图使用显式倒易长度（如 nm⁻¹）的两点已知尺度，沿用现有等比例假设与原请求追踪。未知 TIFF 的新显示保留未知域，只有研究者明确声明衍射域后才按倒易尺度标定；已知实空间对象不能改名为倒易域，旧对象、原文件及标识不变。衍射中心须由研究者在已标定图中选点指定，不取图像中心替代测定。

保存两条同网格、同标定且共用一个精确端点的距离后可算夹角。现有 image_measure 支持两点距离或三点（顶点、端点A、端点B）夹角，沿用既有带符号 XY 几何；未标定仅显示图像坐标角，不推断物理角度。工作台夹角记录绑定两条原测量的对象/清单哈希和端点；矢量点位、中心或标定改变后标为需重测，保留原值。结果表和选中结果的只读图上双射线标注共用该记录。不会据此自动确认物相、hkl或不确定度。

用户进一步明确三入口：左栏“长度”为通用两点测量，“角度”为通用两条共端点保存矢量的夹角，“衍射标定”为独立上下文（倒易尺、中心、反射距离与夹角）；后者不能替代前两项。具体动作在右侧按需显示，禁用原因沿当前选区/标定/忙碌状态给出。标量倒易图必须注册为可编辑显示窗口，域网格键为array，与既有spatial和fft区分；不把数组索引当作实空间ROI或数学FFT频率。
