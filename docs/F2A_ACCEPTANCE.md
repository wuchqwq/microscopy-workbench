## Physics oracle evidence

The executed command is `python -m unittest discover -s tests -p
test_image_gpa_physics.py -v`, with the independent environment. Frozen analytic
targets and tolerance choices are recorded in
`tests/fixtures/gpa_physics_truth.json` and generated by
`tools/create_gpa_fixtures.py`. They were not changed after a failed result.

| Quantity | Frozen tolerance | Observed error |
| --- | --- | --- |
| Affine gauge-removed displacement RMS | ≤ 0.08 pixel | ≤ 0.001271 pixel across cases |
| Affine median `F` component error | ≤ 0.003 | ≤ 0.00002966 |
| Affine median `E` component error | ≤ 0.004 | ≤ 0.00003019 |
| Affine median polar angle error | ≤ 0.20 degree | ≤ 0.00016291 degree |
| Nonuniform displacement RMS | ≤ 0.08 pixel | 0.018275 pixel |
| Nonuniform pointwise `F` / `E` max component error | ≤ 0.003 / 0.004 | 0.00072617 / 0.00071589 |
| Nonuniform pointwise polar angle max error | ≤ 0.20 degree | 0.021676 degree |

An independent fixed-atom, changing-basis-contrast control has exact lattice
displacement/strain zero. It nevertheless produces median interfacial
`abs(apparent Exx)=0.02285037` (about 2.285%) and maximum 0.03368301. This test
passes because the output is explicitly conditional apparent image-lattice
strain, not because the algorithm removes the pseudo-strain. It enforces the
scientific limitation discussed by Peters et al.

Public inspectable physics evidence is
[physics-results.json](examples/gpa/physics-results.json) and
[physics.png](examples/gpa/physics.png). The figure uses gray for invalid support
and separately labels the contrast-only case as apparent strain.

## Actual MCP and Panel HTTP evidence

After `npm run build`, run `node dist/tools/smoke_gpa.mjs` with
`MICROSCOPY_PYTHON` pointing at the independent environment. Optional
`MICROSCOPY_SMOKE_OUTPUT` must be a new absolute directory. The passed `r3` run
took 100.877 seconds; it includes repeated process-start/validation/recovery
work and is not a kernel speed benchmark.

The image is an analytic 256×256 float32 sum of two lattice waves. Requested
reference-wave rows are `[[32,8],[-8,32]]/256` cycles/pixel; observed image waves
are `[[31,7],[-9,33]]/256`. Independent matrix algebra gives `F=K^-1 G`, not
an expected field generated by importing the production solver. The signed
physical metric is `diag(0.023,-0.031)` nm/pixel. The scientific input domain
and its synthetic source are explicitly declared in the tool request.

The maximum error across all checked affine `F` components, including fitted
reference zeroing and parameter revisions, is `6.622e-10`; the corresponding
`E` error is `3.935e-10`. Physical polar rotation error is `3.197e-10` rad and
displacement error is `1.858e-10` nm, against the smoke's `5e-7` guards. These
very small errors apply to this periodic isolated-wave fixture, not noisy real
specimens or the more difficult nonuniform oracle above.

The passed report retains one source hash, one FFT hash and an FFT count of one.
It verifies all original GPA files unchanged after later revisions. Display
views do not add GPA fields; bounded explicit samples retain validity and units.
Fresh clients retrieve saved request IDs and object info without new objects.
The actual Panel HTTP/state PNG was visually inspected for title, units,
conditional interpretation and gray invalid border. No computer-use or browser
gesture was performed.

Sanitized public evidence is [mcp-results.json](examples/gpa/mcp-results.json),
[the component CSV](examples/gpa/mcp-summary.csv) and
[the actual MCP strain preview](examples/gpa/mcp-exx-preview.png). It contains
only synthetic results and no absolute workspace paths or private image data.
Public text copies use LF line endings; original runtime/export bytes and their
checked hashes remain in the retained local workspace.

The ignored local `analysis/2026-10-30-f2a-live-r1` report is FAIL: the smoke
fixture initially used unsupported float64 TIFF. The reader correctly refused it
before GPA; the fixture was corrected to supported float32. The separate `r2`
report is FAIL in the smoke harness after analytic numerical checks and exports
passed: object counting tried to read an unpublished staging directory left by
the deliberately refused overwrite. The harness now counts published
`object.json` manifests only. Neither failure was fixed by weakening a physics
tolerance or changing the science engine. Original reports remain intact.
The separately retained `r3` run is PASS for its complete declared scope.

The numerical core's first suite passed 9/9; an additional missing-band
roundoff regression then passed with the core at 10/10. No observed core test
failure or physics tolerance relaxation preceded those passes. The independent
physics suite separately passed 11/11 on its first execution.

Early workspace prototypes had 3/3 failures because their synthetic TIFF
fixture also used unsupported float64; changing that fixture to float32 fixed
the admission issue. A transient 4/4 failure while new typed domain arguments
were landing was an integration-in-progress result, not a frozen-build physics
failure. The meaningful seven-case integration run then passed 6/7: exporting a
recalibrated GPA sample receipt reached an inappropriate generic NPY renderer
for its CSV instead of refusing stale calibration. The provider was repaired to
handle sample export without that renderer and to reject stale GPA calibration
with `STALE_CALIBRATION_RESULT`. A subsequent test asserted an English word in
the message despite the correct error code; it was corrected to assert that
exact code. The final workspace suite passed 7/7, including sample JSON/CSV,
full-array view export, revision provenance and stale-calibration refusal.
These fixes did not change physics tolerances or erase the earlier failures.
