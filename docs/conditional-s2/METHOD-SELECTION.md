## 选择依据

| 路线 | 证据与取舍 | 建议 |
|---|---|---|
| H0：基线 FFT 峰与上下文 | 提供直接频率观察；仍需区分核心和横竖支持区，也不能把噪声峰当成物相 | 默认保留 |
| H1：连续频率变量投影精修 | 高计数孤立频率有收益；低计数、近邻频率及多峰情况下不稳定，严格合格仅 427/1,464，其余 1,037 回退 | 保留研究候选，不默认启用 |
| S0：固定 ROI 原始均值与参考中位数 | 估计的是总强度差；对当前主要测量目标仍有实用性，不能直接解释为孤立柱占位 | 默认保留 |
| S1：单柱加背景 Poisson 拟合 | 有局部降噪收益，但总 ROI 目标没有一致优势，邻柱贡献可混入目标或背景 | 暂不优先独立推进 |
| S2：多柱加背景 Poisson 拟合 | 更适合分离中心柱贡献，但依赖已提供的几何、形状和宽度；数值可用性不足 | 作为明确附带假设的可选分解路线 |

H1 的正例：H01 高计数条件下，同一 40/40 个合格观察、40 个对应模式，频率 RMSE 从 H0 的 0.01968 降至 H1 的 0.01445 个核心 FFT bin。反例：低计数时仅 10/40 合格，相同对应模式的 RMSE 从 0.11474 升至 0.14938；近邻频率的无噪声对照也出现变差。因此不能仅用无噪声的近精确恢复主张普遍改进。这里判断的是当前候选生成、权重和边界组合，不是否定全部连续频率估计方法。

S2 的价值应按不同测量目标理解。对于总 ROI 强度差，S1/S2 没有一致超过 S0。对于预先声明的中心柱分量，S01 高计数目标柱的同一 20/20 个观察中，S1/S2 的 RMSE 分别为 15.76/5.33；强重叠 S03 为 7.98/6.39。该分量不是原始 ROI 均值，S0 对此不适用。

反例必须一起保留：S10 真实宽度 1.6、拟合固定宽度 1.0 时，真实中心积分为 50，同一 19/20 个目标柱观察中 S2 偏差为 −24.82、RMSE 为 25.14；全九个位置共同合格只有 1/20。零中心柱 S02 也不是 S2 全面胜出。主比较有几何的 1,342 个输入中，S1 完整测量合格 1,309 个，S2 为 993 个；另有 122 个设计上不提供几何的输入。目标柱单独合格不能替代完整参考测量的合格率。

横竖窗口的作用也应保持清楚：H10 的无噪声污染支臂在 H0 和合格 H1 中都可出现核心区域没有的频率。扩大支持区能提供信息，但不能把所有新峰都归属到核心。

## 数学解释与主线建议

STEM 固定模板模型 `mu = X a` 的 Poisson 负对数似然对非负系数是凸的；这只保证在既定模板下求解的性质。模板重叠、柱宽设错或形状不匹配，仍会使分量不可辨或偏置。尤其在拟合区等于读出区、允许整体正比例缩放且不存在截断限制时，真正非零最优解沿尺度方向的导数给出 `sum(mu) = sum(y)`。因此 5×5 拟合总量接近 5×5 原始计数，并不是独立的准确性证据。用 9×9 拟合预测 5×5，才体现额外数据与模型偏差之间的取舍。

H1 的变量投影消去了线性振幅和背景参数，频率问题仍是非线性的。线性块满秩、优化梯度较小，不等于频率具有统计可辨识性，更不等于图像已有物理解释。该方法沿用 [Golub 与 Pereyra 的变量投影思想](https://epubs.siam.org/doi/10.1137/0710036)，不应写成我们的新发明。

建议主线按“观察—条件测量—解释”推进：保留原始数组、校准和 ROI 来源；HRTEM 默认进行核心 FFT 与横竖支持区核对；STEM 默认保留原始目标/参考强度，必要时另列 S2 分解及其几何和形状假设。AI 通过 Skill/MCP 调用已有组件，人可修改 ROI、参考类别和几何；未知、失败和多解状态必须随结果传递。当前不增加专用模型训练。

后续若安排开发，优先考虑 S2 的几何/形状适用性与完整测量可用性，再谈缺陷分类阈值；H1 候选筛选和噪声权重修改应作为新的冻结候选比较。本轮没有启动这些后续实验。
