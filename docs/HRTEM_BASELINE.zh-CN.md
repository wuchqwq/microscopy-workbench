# HRTEM：从观察走到可检查的证据

当前工作的用途，是帮助研究者回答“这里与参考区哪里不同、依据是什么、下一步还能检查什么”。先读原图和已有结果，再选与问题有关的工具。数值通过、图像平滑或多个模块给出一致结果，都不等于真实材料结论。

## 已有能力及入口

| 研究问题 | 现有入口 | 能给出的证据 | 使用边界 |
| --- | --- | --- | --- |
| 感兴趣的位置在哪里？原始数值是什么？ | 原图、ROI、`image_preview`、[数值检查](IMAGE_NUMERIC_INSPECTION.md) | 固定来源、帧、区域和原始数组上的观察 | PNG 是显示；未知标定保持像素单位。不能从缩略图推断物理尺度。 |
| 两处条纹的周期或方向是否不同？ | ROI → 已保存 FFT → 峰质量 → 测量；[手动观察入口](IMAGE_FIRST_DISCOVERY.md) | 所选投影频率、周期、方向及其来源 | 峰可见性、窗函数、带宽、噪声和取区影响结果；FFT 强度不是物相或衍射强度的直接证明。 |
| 同一频带在两区的幅值和相位如何不同？ | [Task A 已保存频带比较](hrtem-saved-band-task-a.md)：`image_method_plan` 的 `peak_roi_comparison` | 每条频带的幅值比、包裹相位差、有效像素、低幅值及相干性 | 只接受一份合格的 `fixed_g` GPA；不是通用原始 HRTEM 或单载波入口。继承联合双频带有效域，一个差频带可能压低另一个的支持率。 |
| 指定模型下能否描述位移、应变或转动场？ | [单畴 GPA](CLASSICAL_GPA.md) | 所选 g、参考、滤波和有效域下的投影场 | 输入必须符合 GPA 条件；参考无应变、单畴和位移模型都不能由有效掩膜自行证明。材料应变证据仍可能不足。 |
| 指定相位场和回路是否有稳定闭合特征？ | [投影拓扑](PROJECTED_TOPOLOGY.md)、[跨方法继续](../skills/scientific-agent/microscopy-automation/references/method-loop.md) | 固定频带、回路及其有效条件下的投影闭合诊断 | 需要相关问题、合格来源和有限预算；共享或重叠 Fourier 支持不是独立实验，不能据此确认材料位错或唯一三维 Burgers 矢量。 |
| 某个结构或取向候选能否解释观测？ | [研究者引导的工作流](WORKBENCH_WORKFLOW.zh-CN.md)、[有限结构比较](MANUAL_CRYSTAL_WORKFLOW.md) | 指定候选与实测几何的相容、冲突及缺失信息 | 需要有来源的结构、取向、标定和对应关系；有限候选相容不是唯一物相鉴定。 |

原始图像或一个可测频率不需要先通过完整 GPA/拓扑流程。若只是比较周期，停在 FFT 测量即可。不要为了使用所有模块，把条带观察自动升级为位错确认。

## 已保存频带比较：如何读结果

1. 记录原始问题、选区及参考区的实际理由。保留同一科学网格和有符号 g；坐标是局部 FFT 输入网格的半开 XYXY 像素边界，不是 PNG 坐标。
2. 分开读各频带的幅值比和相位差。幅值比比较同一滤波频带的 ROI/参考区，不是原始条纹幅值；相位差包裹在 `[-pi, pi]`，没有展开、局部平面去除或频率拟合。
3. 查看有效像素、低幅值数及相干性。支持不足时保持不可用；幅值可用而相位不相干时，仍可保留幅值比较，不能硬给一个区域相位差。
4. 新结果的保存预览和 `peak-comparison.txt` 会显示这些值及下一步分析提示。先回看原区和保存的 FFT/掩膜；确有观察理由才移动取区或参考，用 `image_method_next` 复用频带。它不会重算 FFT/GPA，也不会自动执行提示。
5. 需要局部周期就回到 FFT 测量；需要位移模型或拓扑检查，另行说明前提和预算。同一图上的参数检查彼此相关，不是多份独立材料证据。

9 个有效像素、90% 支持率和 0.9 相干性是明确的确定性摘要门槛，不是置信度、SNR 或误差界。参考区是有来源的声明或工作假设，不自动具有物理真值。

## 做过的验证说明了什么

Task A 交接包含两个合成案例：已知相位改变约 `+0.4/-0.4 rad`、同频带幅值比约 `1.6` 的正例，以及暗区拒绝例。测试还覆盖移动窗口下不变载波、相位不相干时保留幅值、保存重开、修订及篡改拒绝。这些验证数值与工程边界，未验证真实 HRTEM 成像、噪声鲁棒性、材料应变或位错识别。

交接 ZIP、逐文件哈希通过，不等于所有上层记录都能跨运行环境重开。最初 Windows 校验因 9 个解析传递函数浮点值约 `1e-16` 的差异拒绝原 GPA；新的[版本化解析读取契约](GPA_ANALYTIC_READ_COMPATIBILITY.md)只对白名单字段作独立高精度核验，现在两个原 GPA 均可原样读取并返回兼容回执，旧文件不变。但其上层旧 Task A 计划仍因区域相干性归约的末位差异被精确决策校验拒绝；这些非解析字段不在兼容范围内。原 GPA 读取、上层计划读取和新建本机案例必须分别报告。

- 具有独立依据的不确定性、参数敏感性和真实材料验证。
- 条纹终止或滑移的可靠识别、唯一物理解释及自动实验规划。
- Task B 的明确输入、输出和验收条件；交接包只说明尚未实施。
- 原交接上层 Task A 计划在当前 Windows 环境的精确决策重开兼容性。

保存原请求、对象、选区、标定、参数和未知项。超时先查原请求，不重放未知操作；旧记录保持历史语义。下一步分析建议服务于当前材料问题，最终判断需要研究者的材料和实验背景。
