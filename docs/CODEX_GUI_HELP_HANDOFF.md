# Codex 接手：验收前 GUI 收尾与内置操作说明

## 已完成与目标

从实时 main 新建独立 worktree，先读 AGENTS.md、Issue #78/#71、#77/#79 及最新 CI
收尾记录。#77、#79 已合并；不要重复合并。核对当前源码 SHA、CI 选择范围和实际结果，
保护现有 Windows 数据、用户配置、审批、已打开的窗口和旧工作区。

Route A 不变：工具负责计算与保存，AI 有依据地组织分析和提出有限候选，研究者可随时
接管。三层结果仍分开表达；不新增自动真峰认证、实验规划、Agent 框架。
模型由用户自行选择，不固定主模型或子代理。

本轮优先交付：研究者不用回终端或询问 AI，也能知道现在在哪个视图、保存到哪一步、
怎样继续操作。不要把“工程基线干净”说成真实材料准确性或全套 GUI 已通过。

## 1. 导航与窄窗口：先修现有能力，不新建第二套历史

读取 `docs/GUI_NAVIGATION_OPTIONS_20261102.md` 的方案与源码，而不是只看旧现象。
分别复现同会话原图→ROI→FFT、Agent 首次直接打开 FFT、刷新/正常重开。
确认现有 view-original、frame_identity、SavedViewHistory、source_view 指向哪里。

推荐优先利用可核对的已保存空间观察引用；没有引用时明确区分“原观察视图”与
“根据当前标定新建的源帧显示”。不能把后者冒充恢复原来的 ROI、笔记和显示配方。
局部引用/按钮错误可修；若需要新增持久化导航合同或改变对象来源结构，先提交最小
方案、兼容性和代价，与用户讨论后再动。P3/P4 的大改仍没有预先授权。

760×800 已有抽屉：先检查遮挡顶部操作、收起/关闭入口和相机在 resize 后的位置。
保留图像、ROI、科学坐标与草稿；纯布局改变不能重算 FFT 或移动科学锚点。
只收敛现有布局的确定小问题。整体布局/可调侧栏先给设计，不自行重写前端。

## 2. 在 GUI 内实现操作说明（不是只交一份 Markdown）

提供清楚可发现的“帮助 / 操作说明”入口，使用现有前端组件和样式，优先非模态侧栏
或可关闭弹层。说明在本机可读；不要求联网、启动模型或上传样品，不强制首次导览。
键盘可打开/关闭，关闭后焦点返回原入口；窄窗口也可读，不遮住所有主要操作。
打开帮助不能清空草稿、改变选区、切换科学对象或创建计算请求。

内容必须对照当前真实按钮、快捷键和工具能力，不写尚未实现的功能。至少覆盖：

- 打开原图/选数据集和帧：哪些需要明确选择、原数组只读、缺标定可做像素域分析。
- 基本路径：框 ROI→写观察理由→保存→看 FFT→选峰/测周期→修改峰并重测→返回空间图。
- 点选峰、框选区域、平移/缩放的区别；只列实际存在的手势/快捷键。
- “提交中 / 已保存但核对中 / 可接续 / 保存失败草稿保留 / 待查看结果”的区别。
- 有草稿和无草稿时如何查看新结果；“全频谱”与“原图/原观察”的区别。
- 人先操作与 AI 先操作怎样使用同一 Panel；按需 MCP、显式交接，不暗示会自动唤醒 AI。
- 数值结果、可靠性未评估、候选解释的区别；人工修峰不自动表示更准确。
- 笔记超限、PREVIEW_REQUIRED、活跃 helper 上 resume 被拒和请求结果未知时怎样继续。
  未知请求查原 ID，不能换入口重算；不把所有拒绝都说成程序故障。
- 正常关闭/重开和查找保存结果；不要夸大为活跃 worker 崩溃已验证。

说明应短、可扫读，按操作问题组织；详细说明按需展开。可加入基于当前状态的提示，
但不得猜测来源或隐藏拒绝理由。实际功能有阻碍时先报告，不能用说明掩盖缺陷。

## 3. 有界组合验收与性能检查

Windows 上用公开合成图运行一条真实浏览器链：保存 ROI→等待读回可接续→FFT→拖峰→
重测→返回对应空间视图→正常关闭重开。对合并后的精确版本记录结果，不沿用旧 PR
单独成功冒充组合通过；受控延迟/协议注入与真实鼠标事件分别标明。

同时检查帮助打开/关闭、焦点、草稿保留、760×800，以及错误提示可理解。
复用现有失败记录和定向测试；算法未改，不重跑无关科学矩阵。实际请求/调用次数从
事件日志汇总，不让模型凭记忆填。未执行项 NOT_TESTED，保护拒绝和任务失败分开。

如果保存仍显著慢，用少量明确样本拆分提交→provider→Panel 准备→响应的耗时；
两次状态读取很快的既有样本不能证明所有情况，也不能为提速取消持久化/读回校验。
不设未经讨论的性能达标线，不为一次慢样本重写运行时。

## 4. 前端审查与真实样品的边界

独立前端审查材料使用公开合成截图。用户选择审查者后再实际调用；没有调用就只交
材料，不虚报评审完成。真实样品在用户指定文件/数据集、研究问题、标定来源、输出
目录和外传范围后另行进行。不扫描未授权目录，不上传实验图、截图、日志中的私人
路径或 token。#45 仍单独评审，不强加为本轮前置。
