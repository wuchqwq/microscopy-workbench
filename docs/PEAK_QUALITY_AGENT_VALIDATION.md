# 峰质量操作规程与 Agent 行为对照

本轮只增补既有 microscopy-automation Skill 的[峰质量参考页](../skills/scientific-agent/microscopy-automation/references/peak-quality.md)，在入口中路由，并把旧 v2 数值说明更新为实际 v3。没有新增 Agent 框架、概率字段、API封禁或实验规划。参考页按“读取→可选操作→参数代价→停止对应结论→报告”组织，缺少标定/统计资格不禁止仍有依据的观察和候选讨论。

## 文献、诊断与使用边界

[16项文献复核](PEAK_QUALITY_LITERATURE_REVIEW.md)区分原方法前提、草案数学推导和工程建议。原附件不是已验证标准；ZIP及内文件hash已核对。1D峰突出度、光学RAW模型、Gaussian随机场选后检验均没有被移植为二维电镜FFT认证。

当前实际工具提供数值对比、局部峰/中位幅度比、精化说明、共轭和选择截断诊断。它没有合格的SNR、统计显著性、定位区间或候选概率。v3整体对比通过也不保证每个返回峰数值可分辨。`valid`保持原对象语义；新文字不修复未解决的逐峰/物理准入设计，更不能静默给历史对象加资格。

## 实际模型对照与真值隔离

2026-11-02，通过实际子Agent接口显式选择 **GPT-6.1 Sol、high**，分别启动三个无父对话历史的新Agent：`peak_behavior_baseline`、`peak_behavior_updated`、`peak_behavior_valid`。没有使用Astra完成本轮行为测试。服务端更细模型revision、temperature、随机种子未暴露，不能宣称固定模型输出逐字可重复。

前两次各5个相同任务快照；条件为原有Skill+scope和增加参考页后的Skill+scope。第三次仅补一个来源一致的 `valid` 案例。输入来自实际保存/数值结果的白名单投影；用户问题和工具字段保留，文件场景名、seed、真值频率、匹配指标、隐藏评分标准不交给被测Agent。别名是快照中的不可执行引用，不是正式对象ID。E为人工构造的未知请求/超时快照，明确不是实际远端操作失败。

输入、指引和评分标准在调用前写入并保存hash；评价者人工按语义评分，不用关键词命中替代判断。原响应逐字保存，不因结论重跑、挑选回答。这里只测试读取快照后的报告与调用选择；**没有让模型实际调用MCP、操作GUI或执行请求恢复**。真实科学MCP/保存链资格另见 #63 和噪声PR，不能合并计作模型端到端成功。

## 保留的夹具错误

首版快照选择器漏写剂量筛选：A/B/C实际读取D50（hidden mapping误标D500）；D保存特征为D500而附带峰表是D50，且别名image-D/image-A不一致。实际工具结果未改，两个Agent均识别D的来源风险。此为**测试驱动实现错误**，不是科学工具或Agent失败。

原输入、选择脚本、隐藏mapping、hash和两份响应完整保留；没有修改它们伪造干净配对。补测F只修数据选择为D500及一致别名，调用另一个无历史Agent；独立报告不冒充原D通过。完整的源文件hash和时间顺序说明见证据目录。A/B/C按实际载入数据解释，不按误标的剂量分析模型性能。

## 四类问题与停止范围

- **实现错误**：科学DC计账遗漏由独立#63修复；本页未改算法。上述快照选择错误保留并独立补测。
- **测量不确定性**：弱峰、额外局部极大值、定位误差未知。手册不把未知当零，不自行校准SNR或概率。
- **方法局限**：有限支持/窗、混合纹理、模型噪声前提、单域条件。仍可报告条件图像纹理，但停止对应强解释。
- **物理不可辨识性**：相容几何可以支持多个投影/材料/成像解释；不强迫选唯一赢家。

若要改变 `valid`、逐峰数值资格或统计准入，按 [DC设计讨论](FFT_DC_ROUNDOFF_DESIGN.md) 的两条方案另行决定；此次只提交操作指导，相关架构修改仍暂停。
