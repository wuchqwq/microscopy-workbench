# 同一源帧的多 ROI 图像窗口

本轮采用 TypeScript `.mts`，沿用既有 Panel、科学工作区和正式构建，不引入 React。
同一源帧的来源图、局部显示和 FFT 可保留为多个窗口，便于对照 A/B 两处区域。
窗口只是已保存对象的展示引用；provider journal 仍是科学记录的权威。

## 第一阶段：多窗口展示

窗口集合最多五项，足以容纳来源图、两张局部图和两张 FFT。主动“查看选区”或 FFT
产生新保存显示时增加窗口；同一科学网格上的峰、标注和显示修订更新原活动窗口。
标题、布局、平铺和只读缩放不构成科学计算。关闭只移除窗口，不删除对象、测量或历史。
达到上限时保留已完成结果等待查看，研究者关闭不需要的只读窗口后再接纳，不自动挤走旧图。

始终只有一个当前科学编辑器，其他窗口只读。第一阶段沿用 P3“返回空间观察”使来源图
成为当前图，随后可以继续选择另一 ROI。活动窗口不可直接关闭；先通过受保护返回路径
使它变成只读窗口，才可关闭。不同源帧不放在同一集合比较，原记录仍在工作区中保留。

宽屏支持拖动标题、调整窗口尺寸及平铺。点击窗口内容或边框可置顶，只改变遮挡顺序，
不切换科学编辑目标。窄屏优先显示当前编辑图，其他窗口的保存引用
继续保留。观察、属性和结果按需打开。全局待接纳、保存核对和未知请求提示不属于某一
子窗口，不能通过关窗隐藏。

待查看结果存在时，仍可保存当前同网格的观察或理由修订；保存与两次读回核对完成后，
交接仍须等待该结果被处理。新图计算和导航在原待查看引用解决前受阻，不重复派发 FFT。

## 来源和科学语义

每个 FFT 记录准确输入保存视图、源帧、原 FFT 身份和实际整数处理窗口。同帧、同尺寸
或看起来相似都不能证明两个 FFT 来自同一选区。当前交互框与 FFT 处理窗口分别表达。
改选区不自动重算，也不把旧 FFT 重新标成新选区的结果。

源图和 FFT 的当前显示修订与原输入身份分别保留。历史来源关系与当前标定一致性不同：
后续改标定不改写原 FFT 输入，各图按自己的标定版本解释；不因此改变 P3 返回旧来源
的行为。并排展示不确认峰可靠性、应变或物相，三层结果语义保持独立。

只读窗口读取已保存 PNG 和 metadata，不触发 image_preview 或 FFT。资产仍核对准确
对象、同源帧、面板映射、路径和 PNG 哈希/字节预算。失败时明确该窗口不可用，不用
当前图或其他最近对象冒充。MCP 顶层 object、selection、edit_state 只描述活动图；
窗口摘要里的其他引用不是第二个活动科学输入。

## 状态与恢复

PanelState 的可选 window_collection 是有版本、数量上限的展示状态。图像载荷单独按
当前集合中的窗口身份读取，不把五幅 PNG 放进每次状态轮询。布局或关闭操作核对准确
当前对象和集合版本，保留科学选区、草稿、last_operation 和原请求。

owned checkpoint 只增加已有对象的引用与布局，旧档缺字段按既有单图恢复。恢复读取
保存资产；某个只读窗口失效不能清掉当前编辑记录。关闭浏览器不等于 helper 已正常退出，
正式 CLI 中断资格需独立验证。

本阶段仅对受支持活动图恢复窗口集合。不支持的多面板图可暂时保留旧只读引用，但停在
这类图上冷重开会保守退回原单图恢复；不把它宣称为完整窗口历史恢复，科学对象仍保留。

## 第二阶段：显式编辑与返回上下文

“编辑此图”复用当前科学编辑器，切换前后核对对象、窗口集合、草稿租约、待查看结果
及持久化状态。每窗保留有界相机、合法临时选区和选中标注；它们必须匹配该保存对象
与科学面板映射。普通标注自动保存保留当前选择，不用旧窗口快照覆盖新手势。

仅有一份活动草稿及全局编辑租约，不在隐藏窗口另建待保存队列。A→B→A 也更换租约，
拒绝迟到的旧 A 草稿。服务端已接纳而浏览器尚未解码显示时标记“窗口切换接续中”，
暂停科学写入和正式交接。未知结果仅只读核对，不重发切换或科学计算；明确继续旧图
需要更高租约阻断仍在途的旧切换。读回失败时保留本地草稿和恢复入口。

每个新 GUI FFT 在生成时独立冻结准确输入视图的相机与浮点选择。P3 返回 FFT A 时
恢复 A 的输入上下文，返回 B 时恢复 B；不把最新空间选区 B 当成 A 的来源。旧结果
缺少上下文时仅返回已验证的空间视图，不从整数计算窗口猜原浮点 ROI。后来改标定、
修峰和显示修订都不回填或改写旧输入快照。

空间图上的只读虚线框标为“FFT 计算区域”，来自准确源帧和整数处理边界；与科研者
当前浮点选区分别表达。叠加层不拦鼠标、不生成科学标注、不重新计算 FFT。

## 第三阶段：多个可编辑 ROI 与来源交接

“添加 ROI”（R）在空间图松手后保存矩形位置及稳定 ID，再完成原有两次读回。
理由尚未填写时保留未知，不把自动名称当成分析理由。保存核对完成后可连续添加多处，
通过“选择／调整 ROI”点击框体平移，拖动四角或四边控制点调整大小。缩放和平移
限于准确科学面板；原数组不变，不自动计算 FFT。只有一份当前保存／恢复引用，未知
结果查询原请求，不建立每 ROI 的后台提交队列。临时矩形也能调整，仍不自动保存。

ROI 修订使用既有标注保存、撤销和历史记录。FFT 的生成时输入引用和浮点选区不可变；
后来的 ROI 版本单独保留为工作引用。返回旧 FFT 的准确来源后，“查看最新 ROI”明确
打开最新工作版本；旧来源图仍可临时框选探索，新增和修订保存 ROI 前须先打开最新图。
最新工作引用沿已知 ROI 修订、完整保留 ROI 的显示／标定后继及关联 FFT 保留，不能用
任意历史跳转或按时间搜索替换。关闭来源显示后仍可经已保留 FFT 接续；冷恢复重新核对
原输入网格、源帧、保存资产，坏的可选最新引用不破坏有效活动图。

“交给 Agent 继续”先确认当前草稿并读取准确版本，再按需读取只读多 ROI 来源包；
普通轮询不加载所有来源。MCP 的 roi_handoff 仍只描述活动图，multi_roi_handoff
另外携带同帧保存观察和每份 FFT 的准确输入。最多五个图窗、十个去重来源引用，每个
来源最多检查一百条标注；超限或无法核对的内容保留 unavailable，不静默当成全部完成。
频域峰不会投成空间 ROI，来源清洁也不能覆盖活动图的脏草稿或未决请求。

后保存 ROI 与已有 FFT 的关联只表达坐标事实：exact_original_geometry 是原保存
输入坐标关系；same_processing_window 仅表示整数计算区域相同，不能补写原浮点框；
changed_geometry 不能冒充旧输入。标定关系和科学输入可用性另外携带，引用核对通过
不代表测量可靠性或物理解释确认。交接提示只供复制给已连接的 Agent，不自动运行。
