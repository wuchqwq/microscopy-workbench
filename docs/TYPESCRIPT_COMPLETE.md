# Strict TypeScript completion and owner acceptance

The complete Node/MCP, execution/context orchestration, provider adapters, Panel
services, public CLIs and browser business sources are now TypeScript. Python
remains the scientific kernel. This is the integrated acceptance candidate for
Issue #15; the earlier PRs retain the small independently reviewed slices.

## Build and source boundaries

TypeScript 5.9.3 / Node 18 typings remain pinned. ESM/NodeNext targets ES2022 and
keeps Node >=18. Production checking now has `allowJs: false`; it includes only
actual `.mts` modules. Shared/browser checking has no Node globals. There are no
production any/ts-ignore/ts-nocheck escape hatches. Build inventories every source,
requires emitted modules and rejects additional unchecked business JavaScript.

Intentional source JavaScript exceptions:
- `server.mjs`, `science-server.mjs`, `tools/plugin_server.mjs`: tiny compatibility
  startup/export shims into the compiled runtime; not copied over emitted code.
- `scripts/build.mjs`: compiler/package bootstrap, not runtime business logic.
- `tests/*.mjs` and the three `tools/smoke_*.mjs`: test/acceptance harnesses. They
  execute the emitted runtime; they are not alternate business implementations.

Copy the entire `dist/`, including hidden manifests, Python, UI assets and Skills.
Installed code requires no source checkout, compiler, Git or node_modules. The
normal source commands are `npm start` / `npm run inspect -- ...`; installed
package scripts resolve the same emitted entry points. See the original
[audit/build guide](TYPESCRIPT_MIGRATION.md) for setup and package layout.

## Contract guarantees

MCP names, schemas, results/errors, original request recovery and journal formats
remain compatible. Context identity/CAS, worker-versus-waiter state, coordinate
space/sampling, object identity and calibration projections have real used types.
External JSON/HTTP/Python/MCP checks remain active. Remote UI projections do not
acquire scientific identity/coordinate brands. Revision/draft acknowledgements
are distinct from full Panel snapshots, and unknown routes/actions stay unknown.

Old shallow Figure acceptance is intentionally preserved: its checked result is
ShallowCompositionRecipe, not a complete scientific producer recipe. Unchecked
anchors, calibration, style and frame fields stay opaque. No new decoder or
scientific admission/tolerance change was introduced. Python and requirements
files are unchanged from the exact frozen R3 functional commit 3790b3d.

## Validation and repeatable acceptance

At the final source freeze, strict typecheck/build and full compiled Node pass:
295 PASS / 5 existing opt-in SKIP / 0 FAIL. The exact frozen stdio/lifecycle parity
check passes. Independent review also removed all App type-expect-error markers
in memory and confirmed 10/10 real compiler rejections, including shallow replies
and remote coordinate/identity qualification. Erased runtime comparison preserves
original draft/late-result/history/measurement binding operations.

Commands for the source checkout:

```sh
npm ci
npm run typecheck
npm test
npm run test:science
npm run test:compiled:compat
npm run test:runtime:parity
```

The final public legacy fixture is generated by the exact frozen JS domain and
feature-field smokes, then captures its complete schema, original requests,
contexts, Figure recipe and immutable file hashes. It contains 286 objects,
20 FFTs and 919 historical source/science/context/recipe files. No private
specimen data is used. The optional tests require explicit fixture/dependency
paths and exercise an independently copied compiled package:

```sh
# Set MICROSCOPY_LEGACY_FIXTURE to the generated public fixture directory.
# Set MICROSCOPY_COMPILED_PLUGIN_ROOT to this checkout's dist directory.
node --test tests/full-migration-legacy.test.mjs
# Also set MICROSCOPY_PLAYWRIGHT_MODULE; optionally set MICROSCOPY_CHROMIUM_EXECUTABLE.
node tests/compiled-browser-smoke.mjs
```

The legacy check continues old measurement/atlas/context references, exports R3
fields and restores the old Figure without a new FFT. The browser check uses
real Chromium, compiled modules and actual loopback/Python services, including
canvas gestures, draft persistence, annotation recovery and downloadable Figure
assets. Actual final results are recorded in the acceptance section below and
in the integrated PR review comment; a skipped opt-in test is never a pass.

Native client plugin discovery, real specimens, GMS/instrument integration and
macOS execution remain separate qualification scopes. Optional diffsims/real
3Dmol WebGL is not established by the stub viewer protocol tests. No PR has been
merged automatically and the frozen comparison branch has not moved.
