# 分析工作区：阶段一、二操作合同

本版采用同一源帧的分析工作区整体保存。原始图像只读，界面、CLI 和 MCP 共用现有 provider 对象与 request journals。MIT 开源定位不变；Windows 桌面是开发机入口，干净机安装、可分发包和升级恢复属于阶段三。

## 图像上的动作

| 动作 | 实际行为 |
| --- | --- |
| 选择 / 调整 ROI | 默认工具；点击命中框，内部拖动平移，把手缩放；重叠命中与控制点使用同一几何判定 |
| 添加 ROI | 普通画框完成回到选择；每处稳定标识独立，几何修订保留旧科学版本 |
| Delete / 删除选中 ROI | 仅画布焦点中明确选中的 ROI；输入文字时不删图形，无选择不全删；撤回可撤销 |
| FFT | 使用当前明确的实空间选区；无需填写观察理由或先明确保存工作区；保留原浮点选区及实际整数计算范围 |
| 测量 / 峰修改 | 计算记录追加保存；峰修改沿用当前条件性自动重测规则，旧数值在重测前保持历史或待核对 |
| 点击其他图像窗口 | 经过原身份、草稿和未决请求保护后激活置顶；首次激活点击不顺带画框 |
| 返回空间观察 | 走现有来源引用恢复对应空间图和选区；缺少合格引用时明确不可返回；无历史相机时标明新的适应视野 |
| 关闭子窗 | 只关闭显示，窗口列表可重新打开，不删除科学对象或视图记录 |
| 保存工作区 / Ctrl+S | 核对各窗口工作编辑、落实需要的标注修订，然后发布一个明确保存点并读回校验 |
| 结果与历史 | 可选保存 ROI 观察、ROI 对照结果及探索执行历史；打开已有结果不重算 FFT |
| 使用说明 / 桌面 F1 | 可打开、关闭的中文离线帮助；不清草稿、改选区或计算 |

一次几何手势对应一次撤销。正常切窗保留各窗的工作理由、字段、选区及编辑；不把切窗变成反复的保存／放弃问答。可见窗口数仍有界，关闭后的显示引用也有独立上限，不通过放宽科学网格保护来接纳结果。

## 三类状态

| 状态 | 所属内容 | 保存或恢复规则 |
| --- | --- | --- |
| 工作编辑 | ROI、观察理由、标注样式、显示配方及采用的结果 | 即时记录用于接续和异常恢复，但尚不等于明确保存 |
| 明确保存点 | 经校验的整个分析引用清单 | 只有明确保存成功且读回通过才显示已保存；新编辑继续保持未保存 |
| 不可变执行记录 | 已执行 FFT 的真实输入、数组、原请求、测量和历史修订 | 探索后选择不保存也不抹除，不自动归入旧保存点 |
| 显示偏好 | 相机、窗口布局、开合 | 独立恢复，不能携带新 ROI、修改后的选区或未保存 FFT 进入旧分析 |
| 未确认请求 | 正在执行、结果未知或保存回执未知 | 保留原 ID，查询原请求；超时或进程消失不证明从未执行 |

如果后端通过原请求的正式回执证明操作未提交，界面保留编辑并允许研究者明确发起新操作；查询本身不重放。其他未知情况继续保护，不能从错误文案猜测“没保存对象”。

桌面关闭工作区／退出时，只有有修改或待处理恢复内容才询问“保存／不保存／取消”。保存失败保持编辑与窗口；取消继续工作。原科学请求仍未知时保持打开并核对原请求。浏览器页签只有浏览器通用提醒，不等同原生三选项。

## 保存 A → 编辑 B → FFT(B) → 不保存 → 重开 A

1. 在 A 明确保存；随后移动、缩放或临时绘制得到 B。
2. FFT(B) 在分派前冻结经核验的来源、原浮点 ROI、标定和预处理，并绑定原请求；新数组仍由既有 provider 保存。
3. “不保存”恢复 A 的分析引用和工作内容；不删除 B 的执行记录。
4. 重开 A 不自动采用 B，也不把 B 的结果标成 A 的结果。
5. “结果与历史 → 探索执行历史”或 CLI `history` 可独立核对 B。只有合格完成记录可以通过原有 show/return 路径查看其 FFT／空间输入。旧记录缺少证明时保持未知。

崩溃未保存内容另有显式“恢复未保存编辑”入口。先选择恢复或“放弃未保存恢复副本”，再进行新的分析编辑；期间仍可平移、缩放和调整窗口。保存当前 A 不会替你放弃 C。恢复／放弃响应期间出现的新编辑继续受到版本与交互保护。明确丢弃的内容不在下次无提示复活。

如果旧磁盘已经同时留下两个冲突的未处理工作副本，启动会保留原文件并拒绝覆盖，需人工核对；此处不提供自动猜选或静默迁移。阶段三的升级恢复另行验证。

## 当前布局及组件对应

```text
文件  编辑  分析  窗口  帮助                （独立桌面）
保存工作区   保存状态                       使用说明
选择 / ROI / 平移      图像工具与上下文动作
┌─────────────────────┬───────────────────┐
│ 来源图像：多个 ROI   │ ROI / FFT 对照窗  │
│                     │ 当前活动图像编辑  │
└─────────────────────┴───────────────────┘
当前 ROI      FFT / 测量 / 删除选中 ROI
观察与证据 ▸                结果与历史 ▾
```

唯一活动编辑器仍在 `app.mts`，`WindowWorkspace` 负责显示集合和资格明确的切窗。`WorkspaceControls` 负责显式保存／恢复反馈，`settleWorkspaceWindows` 顺序落实停放编辑；`AnalysisWorkspace` 发布引用清单，原 provider 仍是科学数据权威。CLI 复用同一工具、数组与 journals。Electron 只提供原生窗口、菜单和生命周期，不开放 renderer 的文件系统／shell 能力。

更多启动与命令：[Windows 桌面](DESKTOP.md)、[独立 CLI](CLI.md)。测试命令、首次失败和实际鼠标范围以最终组合验证报告为准；此合同不是真实样品或完整 GUI 验收证明。
