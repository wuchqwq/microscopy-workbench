# 研究者引导的晶体学工作流程

[简体中文](WORKBENCH_WORKFLOW.zh-CN.md) · [English](WORKBENCH_WORKFLOW.md) · [项目概览](../README.zh-CN.md)

本指南说明研究者、可选 AI Agent 与科学 provider 如何协作，对应已合并主线 [c69424ac](https://github.com/wuchqwq/microscopy-workbench/commit/c69424ac25a35efd816d68cacd5904f5381c7485)。这是使用指南，不是新的实验或验收报告。

## 各自负责什么

- **研究者：**提出问题和已知样品信息，检查来源与标定，选择或修正 ROI 和观察，复核科学解释。
- **Agent + Skills：**读取实际 MCP schema 与保存的上下文，选择合适工具，自动执行授权范围内的有边界步骤，保留不同解释并说明缺口。内部对象与请求 ID 由 Agent 管理。
- **科学工具：**执行明确的数值操作，保存输入、参数、结果与原请求。语言模型的文字不能代替数值结果。
- **Image Panel / CLI：**通过既有保护查看和编辑共用工作区。显示结果、采用工作引用与明确保存分析属于不同动作。

Agent 可以自动组织一段有意义的流程，无须让研究者逐峰点击、逐步批准数值计算；仍须遵守任务范围和客户端权限，明确缺失信息，并在预算或证据不足时停止。

## 1. 从真实来源开始

按[配置指南](CLIENT_SETUP.zh-CN.md)在独立工作区打开支持的文件，明确数据集、帧，以及必要的标量平面或复数分量。核对 dtype、坐标轴、来源哈希与带符号标定。缩略图用于显示，不能作为科学输入。

缺少尺度时可以做像素域观察，不能编造 nm/angstrom、假定无应变参考区，或把帧序号解释成物理深度。核心不要求实时 DM 连接；导入 DM 文件不等于执行 DM 原生操作。

## 2. 先直接探索，需要时再交接

本地探索可以选择明确的实空间 ROI，直接执行 FFT。**基础 ROI → FFT 不要求先填写观察理由，也不要求先明确保存工作区。**可继续移动、缩放或添加 ROI；已有 FFT 保留生成时的浮点框、整数支持区域与预处理。

需要 Agent 引导的研究时：

1. 明确目标 ROI；使用观察路径时保存观察理由或问题。
2. 使用显式 Agent 交接。Agent 读取准确的当前 Panel、ROI 锚点、来源、标定和可用 FFT/测量引用。
3. 给出科学问题与有边界范围。例如：比较两个选区的局部倒易几何，复用核验通过的 FFT，保留未匹配峰，并说明区分剩余假设还需要什么证据。

交接面向已经连接的客户端，不启动模型，也不把每个图窗变成独立活动编辑器。历史 FFT 的输入和最新工作 ROI 可能不同，不应静默互换。参见[图像窗口与多 ROI 交接](IMAGE_FIRST_WINDOWS.md)。

## 3. 只选择需要的方法

| 问题 | 已有路径 | 解释边界 |
| --- | --- | --- |
| 局部可见什么周期或倒易方向？ | 保存的 ROI → FFT → 数值峰 → 明确测量 | 极大值、谐波、共轭和伪影需要复核；共轭峰不是独立证据。 |
| 两个区域有什么差别？ | 保存的 atlas、局部特征比较、人工晶体学路径 | 有限几何与给定假设，不是自动物相分割。 |
| 某个显式结构或取向是否相容？ | 满足资格的结构工具与有限通用/孪晶比较 | 保留未匹配反射、竞争模型与模型资格；相容不等于识别。 |
| 有预算的空间研究下一步看哪里？ | 多尺度结构场、候选域与主动接续 | 未采样处保持未知；自动图像特征提案仍为实验性。 |
| 给定假设下得到什么投影位移或应变？ | 满足条件的已保存 FFT → 经典单域 GPA | 明确参考、掩膜、度量及伪应变限制。 |
| 指定回路的投影绕数是否一致？ | 保存的包裹 GPA 频带 → 带版本的拓扑证据 | 条件性投影闭合，不是唯一三维 Burgers 矢量或已确认位错。 |
| 选定帧之间发生什么变化？ | 明确序列语义和 ROI 对应 → 联合观察 | 帧顺序不代表深度或分辨率，同尺寸不能证明对应。 |

方法可以组合，但不是必经流水线。使用可选工具前，核实它实际已公布且依赖满足条件。缺少证据时，Agent 应请求信息或停止，而不是把所有图像强行送进全部方法。

## 4. 在图旁复核

通过来源与 FFT 对照、保存的测量查看实际数值证据。频域两个非零点之间的测量线表达差矢量，不自动成为 DC 到反射的间距。

人工修峰后，读取真正提交的坐标和修订测量，只更新受影响的后续证据，旧结果保留为历史。不变且合格的 FFT 应复用，不能仅为刷新报告而重算。ROI、标定或峰版本改变后，旧结果不能静默沿用“当前有效”状态。

分别说明：

- 请求的操作已经完成。
- 数值和来源前提满足要求。
- 某个物理解释得到支持。

操作完成或来源记录清洁，本身不能建立第三项。

## 5. 保存、恢复与接续

工作区区分工作编辑、明确保存点、不可变科学执行、显示偏好与未确认请求。

**保存 A → 编辑 B → FFT(B) → 不保存 → 重开 A：**恢复的是 A 的保存分析。B 已完成的执行留在历史，但不会自动采用到 A。关闭子窗只移除显示，不删除科学对象。

崩溃后明确选择恢复或放弃未保存编辑。科学请求或保存结果未知时，查询原 ID。超时、取消或进程消失不能证明没有执行。重开 Panel 不得重放科学计算。

停止的、具有拥有关系的已注册 helper 按 [Panel 恢复](INSPECTOR_PANEL_RECOVERY.md)操作。旧的未注册档案和不支持状态保留各自限制。晶体证据重新挂接时核验当前依赖；旧卡片可能保持 `restored_unvalidated`。

[CLI](CLI.md)可以检查准确保存的 ROI、比较已核验输入、读取执行历史和查询原请求。已有但不合格或结果未明的 FFT 不属于“缺少计算”。持久来源证明可记录与核对明确的既有依赖，记录、采用与保存分别执行。回溯证明不会把原本不可用的 FFT 输入升级为严格预执行复用资格。

## 证据与限制

声称资格前，阅读[当前状态](DEVELOPMENT_STATUS.zh-CN.md)和对应方法报告。当前文档不会把未合并 STEM 候选、盲测结果、合成测试或历史验收变成已发布能力。Windows 原生交互、macOS/Linux 桌面资格、真实样品物理准确性和干净机器安装均需单独证据。
