# Microscopy Workbench 内部研究试用版 0.1.12

适用平台为 Mac Apple Silicon。本地包自带运行环境，唯一正式试用入口是交付目录中的 `Microscopy Workbench Internal Trial 0.1.12.app`。旧包只保留作证据，不是并列正式入口。内部研究试用，尚未公证、公开发布或通过干净机器安装资格验证。具体通过、失败与未运行范围以交付验收报告为准。

## 当前能做什么

从已有 HRTEM/STEM 图像提出有限问题，保存来源条件；选择 ROI、做局部 FFT、手动选峰/测距、读取原数组剖线及区域统计；在明确适用的清晰 HAADF 图上找亮峰候选并人工修改；保存分析并在原位置恢复。操作基于原科学数组，预览亮度、缩放、Gamma 和图面标签是显示层。

不能据此自动确认物相、晶面指数、应变、元素、占位、真实缺陷、仪器分辨率或深度。候选点与人工线索不是模型结论。模拟样例验证的是软件行为、几何与来源链，不是真实材料实验结论。

## 第一次导入

1. 打开应用，选择一个新的、专用的分析工作区目录，再选择只读原图。后续可用“打开图像…”选择新图及其工作区；取消选择会保留当前分析。不要把原图当作输出目录。
2. 本包原生入口提供 `.tif` / `.tiff`。支持有限的普通二维单通道灰度页，存储 dtype 为 uint8/16/32、int8/16/32、float32/64；多页文件需明确选择帧，用户界面从第 1 帧计数。RGB、调色板、复杂/nD 布局、float16、64 位整数和非有限像素不在此入口范围。预算超限会拒绝，不静默降精度。本 TIFF 入口不把 XResolution/YResolution、ResolutionUnit 或描述中的 pixel_size/unit 自动当作物理标尺；未显式标定前停留在像素域。核实来源后再画已知长度线或明确填写 X/Y。
3. DM3/DM4 的底层可选适配器仍保留，但所需 RosettaSciIO 0.15.0 未随此包提供，因此不属于本次原生试用入口。不要把 RGB 缩略图转换为可测科学图，或把缺少解码器误写成导入成功。
4. 点击“来源与模态…”，选择模拟/实验/未知，以及 HRTEM、STEM-HAADF、STEM-BF、其他或未知；填写实际来源、成像条件和缺失项后应用，再明确保存工作区。这些均为用户声明，系统不从文件名或画面认证来源。未声明时显示未知。取消或 Esc 仅放弃这个窗口里未应用的输入。
5. 输入条件不会设置物理尺度。到“图像标定”画已知长度线、填真实长度与单位并预览，确认后应用默认等方标尺。特殊的分轴采样通过“高级：分别设置 X / Y”编辑。支持 XY 不等采样及有来源的轴符号；不能填写示例值冒充仪器标定。没有有效标尺仍可做像素域操作，不能输出可信 nm/Å 或物理取向。强度单位与空间标尺是不同条件，归一化模拟信号不是电子计数。

## 一条有限的 HRTEM 路径

例如问：“指定局部区域的图像周期是多少；人工改选峰后是否稳定？”先记录这个有限问题及采样、CTF/离焦/厚度等已知和未知条件。框选 ROI 后做 FFT，核对整数计算窗口、窗函数与减均值设置。在保存 FFT 上手动选点并测量；移动峰点后检查新测量与旧历史。方向是图像坐标中的方向，不能把单个手选频率直接当作晶面、物相或应变。

FFT 来源入口可返回生成时的准确原图与 ROI，不需要重新计算。窗口、手动选点、有限栅格、采样和定位的不确定性必须保留；放大频谱不增加频率分辨率。比较显示时注意独立自动拉伸不是定量对比。保存整个工作区，退出后在原位置重开，核对问题、选区、结果、标定和历史。

## 一条有限的 STEM 路径

例如问：“研究者指定的两处亮峰相距多少，穿峰原数组剖线是否有两峰及低谷？”先确认探测模式、采样和信号意义。画距离线进行测量；另画适当长线读取原数组剖面。首版剖线是一像素宽、最近邻取样，显示点数可以多于不同源像素数，不能当作亚像素拟合或独立重复观测。

清晰 HAADF 图可在 ROI 上进入“找柱候选”，另行勾选清晰亮柱声明，核对距离/阈值等参数。已声明 BF、HRTEM 或其他非 HAADF 模态时不能把该工具套上去。门槛依赖实际来源和人的确认，不是图像自动识别探测模式。模糊重叠、未知条件、缺失计数/背景及参考资格时应停在候选或条件不足。

拖动、补点或撤回候选后检查保存的科学锚点；重复检测保留已有人工移动与撤回，不补理想晶格。手动测距仍是指定端点的几何量。对强度异常可用准确的同形窗口和原数组统计做反证；移动 ROI 若改变差异方向，应撤回“稳定异常”的解释，保留原值与原输入。不能把亮度差直接当成元素、占位或缺陷确认。

## 保存、纠正与安全停止

“应用”更新工作编辑或生成版本记录；“保存工作区”才形成明确保存点。“导出”是图像/数值副本，不能替代可继续分析的保存点。原图、immutable 科学执行、工作编辑、显示偏好与显式保存点分别保留。

改标尺、点或选区后，检查依赖失效/待重测状态。选择原测量行并“更新选中测量”，不能把旧物理数值静默挪到新标尺。旧测量、旧标定与原请求应可追溯。只改显示效果不应重做科学计算。重开读取保存结果，不自动重连模型或重算。

遇到失败/超时/中断：

- 已失败、未提交、仍未知、已计算但未接受是不同状态。保留原请求身份；“查询上次原请求”只核对准确原执行，不是再次计算。不要换一个 ID 重试未知效果。
- “有新结果等待查看”表示结果已写入但尚未进入当前视图。先处理当前草稿，再查看原结果；不能把它当作已应用/已保存。未知、输入不匹配或更晚未决请求仍应受保护。
- 优先正常退出。未保存提示可以取消返回；“关闭提示”后可核对当前窗口与内容；有未保存更改的正常退出使用“保存 / 不保存 / 取消”。若仍受未决状态阻止，可从文件菜单选择“保留恢复记录并退出…”，阅读确认说明。它只等待本应用后台排空并保留已写入的原请求/恢复记录，不是 Save 或 Don't Save，也不会强制结束进程；尚未写入或未应用的输入可能丢失。若排空仍未完成，应保留现场并报告，不能宣称已退出或保存成功。
- 再次打开后先检查恢复记录和原请求，明确恢复或保留最后保存版本；不要自动重放未知操作。恢复退出不提供跨目录迁移资格。

工作区绑定创建位置。直接复制/移动可能得到 `WORKSPACE_LOCATION_MISMATCH`：原记录保留。不要改绑定、source/hash、pending 或修订号来绕过；在自己的原目录打开，或新建工作区重新导入原图。冻结旧失败现场不要操作。旧 pending 的迁移恢复及个别关闭时序仍须单列验证，不能从新建工作区成功推定。

## MCP、本地功能与 AI 边界

正式本地 stdio 入口是该应用内自带 Node 加 `Contents/Resources/app/runtime/server.mjs`，配合同包 Python 与明确的科学工作区。连接模板和本轮实际协议核对见交付目录，不自动修改现有客户端配置、权限或安全设置。应选择一个连接入口，避免同一工作区重复注册旧、新两个服务。

MCP 工具可用、数值/来源可读，均不等于模型已经看到图像或完成研究。点击“记录研究问题”、手工填写 supports/opposes/unknown 和撤回理由只是本地研究者行为。自动科研发问、候选解释、接受纠正及正式模型外发闭环必须有实际模型/产品证据才能判通过。

本地试用不等于授权把图像或测量发送到外部模型。每次外发应遵守当前宿主的权限与数据边界；不能更换入口规避拒绝。AI 环节尚未获得完整端到端验收，离线候选演示、手填解释或测试替身不能代替真实模型证据。

## 图像标定（画线优先）

从左侧“图像标定”进入，点“画一条标定线”，沿原图中已知标尺任意方向拖线。仅按住 Shift 按源坐标拖动主方向锁定水平或竖直（不是 45° 吸附），Ctrl 不用于拉线约束；缩放和平移不改变源像素长度。点“填写这条线的真实长度…”，输入长度和 nm、Å 或 µm，预览将同时设置的 X=Y 每像素距离，再明确应用。这里只验证软件几何；来源不明的图不能猜一个真实长度。

已有非等方 X/Y 会完整列出并自动展开分轴设置。打开、画线、折叠、聚焦或取消均不修改标尺；以新标定线替换时额外确认等方假设。高级设置可以分别修改两轴，单位切换对两轴等值换算，完整数值可读可编辑。未应用的输入需应用或撤销才可保存退出。应用后旧物理测量显示待重测；显式重测、保存和原位置重开，保留标定线、长度、单位、原请求与历史。

## 直接画角度与亮峰候选

点“角度”，在同一幅图依次点顶点 O、第一边端点 A、第二边端点 B，再计算 ∠AOB（0–180°）。不需要先保存两条距离或填写坐标 JSON；三点、同帧来源、标定及原请求随测量保存。尚未完成时可取消，完成后仍需保存整个工作区。未标定时只报告源坐标几何角；标定后区分图像角与物理坐标角。旧“两条已存矢量”工具按需展开。

找柱用于清晰 HAADF 源图 ROI：明确数据条件后点“生成亮峰候选”，再直接拖点移动、在图上补点或撤回选中候选。“高级：检测参数”保留原工具默认值与编辑；实际参数始终记录在检测结果中。重复检测保留已有移动与撤回，候选不是元素、占位或缺陷确认。已声明 BF / 其他非 HAADF 模态不会因勾选条件被改成 HAADF。

## 正常退出与提示关闭

有未保存更改时，退出提供保存／不保存／取消。保存核对成功才关闭；不保存回到上次明确保存点，保留科学执行与原图；取消保留窗口和内容。正在完成的原保存会被等待，不提交重复保存。退出提示可关闭；若退出结果尚未确认，文件菜单“查看本次退出进度”只核对同一个原关闭命令，不重放保存、丢弃或科学请求。恢复退出是保留已写入恢复记录并等待本应用后台排空，不是保存成功或强退。

显式打开图像标定时，无需先创建或选中 ROI。标定、原始精度和分轴输入使用正常可滚动属性栏；关闭标定后普通空属性仍可紧凑显示，查看、聚焦和开合不会写回格式化值或改变相机。

打开图像标定或画标定线时只将属性栏滚到起始处，不滚动外层图像容器。标定开合不作为平移或缩放操作。

冷恢复相机前先同步草稿状态行的实际可见性；仍有未知原请求或未保存状态时保留状态提示，不通过隐藏真实风险改变视口。视口尺寸改变与同布局相机往返核对分别记录。


## 本轮新增：有限研究接续（本地工具，不是AI自动研究）

左侧“有限研究接续…”入口用于下面两个已有provider任务，不需要填写对象ID或JSON。

1. HRTEM先打开含有合格fixed_g频带的原工作区，在菜单选已有频带；原GPA诊断图在只读预览中展示，保留可编辑原图窗口，返回准确原图；画目标区并指定角色，再画一个参考区并加入，填写参考依据，明确比较。不会为所有HRTEM自动生成GPA。比较保留原频带、两条方向、目标与参考及缺失条件；支持不足或相位不可归约时保留null和原因，不能作物相、应变或缺陷结论。
2. STEM在原图指定目标、全部1–8个同尺寸参考和原预期点，分别填写位置、参考和通道／信号依据。点是研究者给定的先验，不吸附亮峰。执行后逐项查看目标均值、每个参考均值及差异，参考冲突不靠中位数掩盖。未知条件如实保存为条件不足，可从该结果修订条件并沿原证据复核；改变点或ROI需明确另建任务，旧链保留。
3. 只有保存的复核确实提出合格建议时，才有“明确执行穿过原预期点的建议剖线并接回”。沿用建议的原请求和采样，不自行改端点；保留原统计、全部参考和旧剖线。结果仍是最低一维原始观察，不能确认空位、元素、占位或物理原因。

矩形沿用已有ROI向外覆盖整像素规则，并显示实际范围；点和内部数值保持原精度。默认文字适当格式化，完整来源和原请求在按需详情中。

研究步骤开始前冻结输入和分阶段原请求。已完成步骤不重算；结果未知只能查询原请求，查不到文件也不能认定未执行。查询确认完成后，再明确接续尚未提交阶段。冷恢复到另一保存帧时，可先查询未知原步骤而不切换画布；继续科学步骤仍要求准确原帧和已处理的恢复状态。未提交表单只在当前窗口保留，不声称随退出保存。

完成结果独立持久保存在原provider工作区，清单重开时只读重建；仍请显式保存可继续研究的工作区。结果卡片“导出此研究结果副本”复用image_export，带原数值、报告、来源与标定；频带比较不复制GPA父数组，若需要应另行导出原GPA。原图/ROI/标注测量图可沿用顶部科学导出、论文出图及组合图版，剖线CSV沿用数据结果。组合图JSON依赖原工作区，不是独立可携带的完整项目。

历史0.1.11-r5中CIF因缺ASE和指定diffsims禁用；本0.1.12候选已显式打包依赖，验收范围见下节。真实持续按Shift拖动仍未验；正式模型看图、解释和接受纠正闭环受限、未验证，未更改客户端或模型配置。


## 本轮补齐的准确边界

本候选显式打包完整ASE/diffsims0.7.0及其固定依赖闭包，许可证和对应源码材料随包保留；CIF仅做1–3个给定结构/明确投影/独立标定与已保存反射的几何比较，不自动索引或确认物相。具体原生验收与失败例见本轮外部报告。

真实按住Shift拖动仍需要人工实机验收：现有正式原生工具没有持续modifier+drag能力，不用逻辑测试代替。待唯一候选就绪后使用本轮隔离公开样例一次核对。

本轮已实现保存空间图/ROI及显式选择的当前测量、raw统计的本地冻结核对；同线程纠正接口复用原已完成thread/turn和原请求围栏。该本地核对路径在创建真实宿主前阻断发送，离线合成peer仅验证软件合同。本候选不得称正式AI看图解释闭环已通过，不修改客户端/MCP/模型/安全配置。


## 图像与证据的本地核对

先应用绑定当前保存空间图的研究问题；局部问题先保存ROI空间图并在该图应用问题。点“核对图像与所选证据（不发送）”，选择同帧、同标尺且落在保存图范围内的当前距离/角度记录和raw统计。没有可选记录时可以只核对图像，不自动计算。原生预览冻结准确PNG、源图/帧/ROI、标尺、选中数值、原请求及哈希；查看详情不改数值。关闭预览或选择取消不发送；菜单“记录已核对本次范围（不发送）”只保留本地核对记录。

原模型回合确实完成且仍持有准确原宿主时，可明确填写纠正问题：先按原问题保存/核对机制应用，再冻结原thread/turn的下一回合输入。旧问题、图像范围、回答、工具审计和每轮绑定保留，不能用另一会话冒充接续。重新打开后只读历史不自动恢复模型宿主；unknown原请求只用“核对原请求（不重试）”。本轮没有真实模型回合，故不能用这一入口宣称模型已理解图像或接受纠正。
