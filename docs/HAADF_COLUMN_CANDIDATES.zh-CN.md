# 清晰 HAADF 原子柱候选（第一版）

用途是减少清晰亮柱图中逐个手点的工作量，不是材料、原子种类或柱数识别。原始数组只读，检测和人工标注都留下独立保存记录。

## 操作

1. 打开原图，选一个 ROI。点击左侧“找柱候选”，确认输入为清晰 HAADF 亮柱图。
2. 点击“在选中 ROI 找候选”。程序读取保存的原始标量数组，不读取截图或经过亮度/伽马调整的 PNG。候选以黄色小圆圈显示。
3. 选择/拖动工具可移动候选。点击“补候选点”，在图上点选后点击“应用标注修改”。选中点后用“删除选中点”撤回；历史记录不删除。
4. 再次检测只补充新点。已有点、移动前的检测位置、已撤回点会在最小间距范围内抑制重复。所有已有标注的坐标、文字、状态都保留，不会恢复被删点或按理想晶格填空。
5. Ctrl/Cmd+S 明确保存工作区。重新打开同一目录读取保存标注和原始检测证据，不自动重新计算。

切换到另一个源图后，HAADF 确认会清空。确认是研究者声明，不是程序从亮度推断的采集方式。

## 方法和保存证据

- scipy.ndimage 3×3 局部亮峰；按亮度和 Y/X 顺序确定性地进行欧氏最小间距抑制。
- 默认最小间距 3 源像素，相对阈值 0.1，局部对比阈值 0.05；平滑 sigma=0。可明确选择 ROI 内高斯平滑，不改变原始数组。
- 固定的保守噪声门槛是 ROI 相邻差分 MAD 估计乘以 6，高于 ROI 中位数；平滑后仍使用原始估计。当 MAD 恰为零但仍存在相邻变化时，使用非零绝对邻差偏差的中位数作保守回退，避免稀疏量化数据把门槛变成零；回退也可能拒绝真实稀疏亮点。它只是对比启发式，不是六西格玛显著性、置信度或电子计数模型。
- 源坐标使用整数像素中心 XY。ROI 为半开边界，界面将浮点选框向外取整，严格检查源支持，不裁剪。第一版没有亚像素拟合。
- 平台峰、ROI 最外层像素中心不自动定位；未分开的宽峰通常保留一个候选。不会强行把模糊 dumbbell 拆成两个。
- `image_column_candidates` 返回普通不可变标注视图。对象目录的 `column-candidates.json` 保存版本、模块和输入数组哈希、参数、实际 ROI、噪声估计、全部原候选和新增/抑制记录。标注 note 保留其检测对象和原位置，人工修正走现有标注修订链。

## 边界

每个视图沿用现有 128 条总标注限制（包括 ROI 和撤回记录）。超出时整次拒绝并保留原状态，不截断结果；可以缩小 ROI 或提高阈值。它不适合以理想晶格自动恢复弱柱，也不提供物理分辨率/柱数/元素/缺陷结论。

相关噪声、孤立热像素、污染、扫描条纹、强背景梯度、量化或密集结构可能使启发式门槛失效，产生误点或漏点。相对阈值和间距都应由研究者根据图像尺度检查。检测点数不是物理原子柱数。

## 验证范围

有独立数值夹具覆盖强弱亮峰、三固定 Poisson 噪声种子、清晰近邻、不可分重叠、单椭圆、空白/纯噪声、非方图与非零 ROI。初版相对阈值在纯噪声上误检，记录失败后增加保守门槛；固定夹具回归无新增漏点，纯噪声候选为零。这不是独立泛化或真实材料准确率证明。

真实 Python provider、MCP stdio、Panel HTTP 和 Mac 原生 GUI 均覆盖检测、手动增删拖动、重复检测、保存和恢复。具体结果与仍未测试的物理材料范围由本次验收报告分别记录。
