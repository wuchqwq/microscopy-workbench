# 复现、访问与证据身份

这是事后整理的复现索引。原始成功、首错、失败、限时未完成和未测的状态均
保留；重新运行得到的新结果必须使用新目录、新运行身份及自己的版本记录。
不要重放旧未知请求或覆盖原数据来“恢复”历史。

## 从Git直接取得

1. 使用记录中的精确commit检出独立副本，阅读该版本AGENTS和依赖说明。
   当前工程基线为 `db2d71383bb1d3b50e8dba4701553550d016e46e`，
   主线起点为 `c69424ac25a35efd816d68cacd5904f5381c7485`。
   当前文档提交不表示这些功能已经合并main。
2. JSON来源记录的`git`条目给出ref、仓库相对路径及精确blob字节SHA256。
   `git show <ref>:<path>`可读取原版本，避免换行转换或当前工作树覆盖历史。
3. [HRTEM原样脚本](reproduction/hrtem/README.md)和
   [STEM原样脚本/协议](reproduction/stem/README.md)带来源hash、所需相对布局、
   固定版本和输出行为说明。它们是原样归档，**本补记没有执行这些实验**。
   必须复制到新目录，并按其README准备兄弟checkout和依赖；不要直接在此目录运行。
   此归档目录通过专用Git属性保留原始字节；校验应比较`git show`取得的blob与
   collection manifest。不要用自动换行转换后的哈希替代来源哈希。首个补记提交
   之后的字节保全修正也保留在Git历史；该修正没有改变实验参数或算法。
4. [小型基线输入及参数](reproduction/baseline-smoke/fixture.json)包含有限float64
   周期纹理代理和原质量受限STEM输入。它们只服务指定ROI工程烟测，不是方法
   头对头数据集，也不能当真实样品或盲检。数值数组应由其TIFF读取，PNG只作显示。

原样物理生成器保留单层MoS2结构、固定删除与剂量/种子；需要独立官方abTEM
环境。点代理脚本依赖对应03ea产品checkout；原环境完整精确lock缺失的部分
已在manifest明示。不能以新环境的安装成功冒充旧环境完整复现。

## 受控而未公开的材料

完整图像矩阵、NPZ/势场、模型/工具收据等大文件按JSON中归档basename、成员和
SHA256保存在项目维护者的受控证据库。访问应向维护者索取指定hash的脱敏包；
含账户字段、内部消息或原始私有日志的材料不随Git公开，不得要求读取凭据
来解密/补证。记录中的控制目录名是证据索引，不是公共下载URL。

当前没有为这批全部大文件登记已发布的持久对象URI/数据DOI。SHA256能识别文件，
不能保证长期可访问。论文投稿前需要维护者完成备份、公开纯合成生成器/允许
的数据，或提供受控访问说明，再补真实持久链接。此项目前是待完成工作，不能
臆造远端位置。缺少主manifest的并行S2也不能仅凭交接数字重建或宣称通过。

导航生成器可从Git取得；原导航评分器包含会话读取/身份输出逻辑，因此未原样
公开。其来源hash和这一缺口已记录。公开可复现评分仍需未来单独清理、审阅，
不能将当前归档说成完全独立的一键复现。

## 新实验如何登记

- 先保存代码commit、输入字节hash、生成器/结构、参数、单位、噪声种子、窗口
  与预算、匹配/评价规则和停止条件；记录真实环境与可选依赖，不推定物理标定。
- 原始输出和全部尝试分别留存。已知ROI、AI自主选择、自动发现，离线数值、
  真MCP、真实模型、物理模拟和真实样品分别计数；相关窗口与同结构噪声重复不
  自动成为独立样本。请求配置与实际可观察的模型/effort收据也应分开。
- 修改协议、门槛或后验诊断时生成新版本。物理225点10.034456% FAIL保持不变；
  18点或24点诊断都不能替代。未运行、缺失C27和严格盲态未确认须继续明示。
- 方案比较应保留困难条件、误报、漏检、拒判/unknown、耗时和资源，不能为了
  让全部通过而挑样本或调整阈值。算法选择与完整矩阵由后续Astra方案另行登记。
