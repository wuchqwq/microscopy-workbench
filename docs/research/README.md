## 数据可用性和保全

本提交保存脱敏事实记录、源指纹、部分原样生成器/协议和小型合成输入，
不包含内部对话、账户资料、原始私有运行日志或私人样品。
完整大文件/运行收据仍在项目受控证据库，按记录中的归档basename和SHA256索引。
这不是已公开的长期对象存储或数据DOI；不得把本机位置当成公开持久链接。
如受控材料不能公开，论文须明确访问条件、缺失范围和可重新生成的部分。

[复现与访问说明](REPRODUCIBILITY.md)区分可直接从Git取得、需要受控归档、
以及尚待补证三种状态。保留错误和缺失，比事后补成“全通过”更重要。
