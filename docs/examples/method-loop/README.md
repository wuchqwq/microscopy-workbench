# First cross-method loop: public acceptance evidence

The actual Plugin MCP/Python run passed on four public analytic textures. Each
case reused one saved FFT and initial fixed-g GPA. The active strategy selected
an explicit extra reflection GPA and then raw wrapped-phase topology for the
positive texture and intensity-identical contrast vortex. It stopped before
extra scientific calls for the smooth displacement hotspot and fixed-seed noise.

Both strategies had the same additional caps: two method calls, zero new FFT
pixels, 131072 GPA band pixels, and 5328 conservatively reserved band-path
samples. Completed topology retained three bands and used 2664 band-path
samples. All actual refused submissions retained their call reservations and
elapsed time. Missing information, immutable information patches, zero-budget
stops and fresh-client recovery also passed.

Positive active elapsed was 54.4 seconds versus 7.4 seconds for the fixed
sequence; contrast active elapsed was 30.7 seconds versus 6.3 seconds. Active
timing includes plan, journal, receipt and immutable-record checks. This single
run establishes no runtime speedup or universal strategy superiority.

The positive and contrast-only images have identical intensities, yet the
contrast-only model prescribes zero material displacement. Both therefore
remain conditional, `hypothesized` image-phase evidence. Smooth zero net
winding does not establish defect absence, and this selected noise control is
not a general noise detector.

The historical full report is unchanged. A separately labelled read-only
supplement checked original failed-request queries and immutable journal
identities. Its first attempt retained a harness failure caused by assuming an
ordinary MCP error was JSON; the corrected gate matched its exact standard
error text. No scientific threshold or production kernel changed.

These artifacts do not cover an ordinary model session, GUI gestures, real
specimens, GMS/DM, hardware, or actual lost-response/cancellation injection.
