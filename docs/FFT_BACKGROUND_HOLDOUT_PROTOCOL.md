All scenes have 128×128 pixels and a weak cosine of relative amplitude 0.02 at input q=(8,5)/128 cycles/pixel. Normalize each positive sampled ideal signal to mean 1 and multiply by 500 expected signal electrons per pixel. Pixelwise observations and their scientific distinctions:

| Scene | Observation | Expected count or offset, and role |
| --- | --- | --- |
| signal | P(signal) | Baseline; shot variance equals signal expectation. |
| digital_offset | P(signal) + 100 | Post-count deterministic numerical offset of 100 counts; no added variance. |
| physical_background | P(signal) + independent P(100) | Additional physical background contributes 100 expected electrons/pixel **and** 100 electrons²/pixel Poisson variance. |
| read_noise | P(signal) + independent N(0,5²) | Read noise adds zero mean and 25 electrons²/pixel variance; negative values are allowed. |
| affine | P(transformed signal) | Same physical signal model under known A=[[1.08,0.06],[-0.03,0.94]] and shift (3,-2) pixels, not another noise term. |

Here P(λ) is independently sampled per pixel. The Poisson signal is sampled first with NumPy `default_rng(seed)`; physical background Poisson or independent Gaussian read noise is sampled second. The same seed gives an exactly paired signal Poisson draw for signal/digital/physical/read scenes; affine has a different Poisson mean and its random draws need not be paired numerically. Digital offset and physical background both raise expected pixel levels by 100 but affect variance differently; the physical background also reduces modulation relative to the total mean. These are synthetic counting models, not a complete microscope or detector simulation. No real-world electron-to-digital calibration is asserted.

Signal truth is prescribed before sampling, not estimated by the tested FFT. For affine coordinates u=A x + shift, output q=Aᵀq_input; translations alter phase, and no claim is made about whether an actual affine distortion originates in the microscope scanner or specimen. The manifest records the input and effective q, affine matrix and shift, the `u = A @ [x,y] + shift; effective q = A.T @ source_q` convention, period, direction modulo 180°, model and per-file hashes. Save each ideal expected image as float64 NPY with canonical array and file hashes and each noise-free/noisy observed image as float32 TIFF with canonical array and file hashes. The ideal expected image includes the prescribed physical background or digital offset, while the TIFF contains the actual float32 quantization. The manifest's evaluator-compatible `dose_expected_e_per_pixel=500` denotes **signal dose**, not 600 total for the physical-background scene; use its separate physical-background and offset fields.

## Matrix and fixed evaluation

Each of five scenes has one deterministic noise-free expected-count source plus 16 noisy observations at never-used holdout seeds 1000–1015: **85 image sources**. This is separate from the earlier 100–115 development data; do not select seeds based on results. Reuse the current evaluator with the v3 repository only. Run four fixed combinations per image, yielding **340 full-image raw evaluations**: primary Hann with mean subtraction=true and secondary window=none with mean subtraction=false; both use threshold_rel=0.05, max_peaks=16, min_separation_bins=3, DC exclusion radius=3, with refinement `none` and `quadratic` separately. Neither rules nor thresholds are adjusted after viewing outcomes. Same-seed contrasts support matched comparisons but do not make the 16 trials a sample of all possible microscope data.

Primary descriptive outcomes by scene and configuration: attempted/success/error counts; true component matched count and denominator; unmatched conjugate-candidate groups per image and count with extras; matched-only absolute period error and modulo-180 direction error with denominator, median and empirical p95; retain per-seed peak rows, q/period/direction errors, source identities and exceptions. Reuse exact integer-bin conjugate grouping and independent one-to-one 1.5-bin truth matching from the existing evaluator and independently audit it. The 1.5-bin convention is not a significance threshold. Direct pairwise digital-offset comparison should show whether the fixed processing responds to an added deterministic offset; compare shot-variance and read-noise cases separately, without attributing all differences to a generic background or SNR. If exact baseline/digital pairing or expected background algebra fails, stop and preserve evidence.

Do not turn numerical peak candidates into p-values, statistical significance, physical-lattice claims or a specimen error rate. Empirical p95 is not a confidence interval, and matched-only errors omit misses. One carrier cannot establish a two-direction lattice or identify scanner versus material strain. A raw `diagnostic_*` output does not become a public saved feature status. Existing public/full-chain work is separate and must not be changed or silently incorporated as holdout evaluation.

It validates the parameter SHA and exact identities, and compares actual saved values with the frozen raw tier. Report public statuses separately; none is a calibrated physical admission test.
