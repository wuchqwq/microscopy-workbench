# 外部正式 MCP：当前图像、ROI 与数值结果回显

此流程复用完整科学 provider 和工作台，不需要测试专用工具桥。
外部客户端与工作台必须连接同一个实际科学工作区。连接方式见
[CLIENT_SETUP.md](CLIENT_SETUP.md)。本增量不修改客户端配置、审批策略，
也不把内置“公开合成样例”发送入口改成任意图像发送入口。

## 正式操作链

1. 研究者在工作台打开图像、选择区域或线段，在已连接的客户端提出问题。
2. Agent 调用 `image_panel_current`，核对当前图像、`roi_handoff` /
   `stem_handoff` 的实际源坐标、当前草稿修订及标定。保存 PNG 与当前
   尚未保存的选择分开返回，不能从旧截图猜选区。
3. 数值统计和剖线用 `view.object.object_id` 作为 `image_statistics` /
   `image_profile` 的输入，并使用刚读取的源坐标。FFT 的原始帧/标定准备
   配方是另一条路径，不能把它的输入 ID 当作数值回显的默认绑定。
4. 保存原科学请求 ID，执行正式数值工具。结果已保存后，用
   `image_panel_show` 的既有参数显示该结果。它将 statistics/profile
   放入现有“统计/剖线”结果槽，不生成 PNG、不替换画布、不重算。
5. 研究者改选区域后再次读取 `image_panel_current`。新选择不改写旧结果
   的原 ROI、剖线、请求和标定。明确保存工作区后，重开读取原数值记录。

只接受完成的原 provider 对象。结果必须属于同一准确帧和标定，且其科学
网格与当前图明确相同；普通预览未投影科学网格时，结果的准确保存输入
必须就是当前图像对象。相似边界、相同文件名或最近结果不能替代该绑定。

## 并发与恢复

- `expected_object_id` 和 `draft_revision` 绑定刚读取的视图。数值记录
  不使用图像结果队列；视图变化、较新/未提交草稿、活动手势或未决请求
  会拒绝数值采用，不覆盖编辑，也不为了展示再算一次。
- 呈现 ID 与科学请求 ID 分开。相同呈现 ID 和参数只读取原不可变回执，
  不把历史结果重新盖到当前数值槽。之后另读 `image_panel_current`
  才是当前状态。
- 同时保留最近一次统计和剖线的原对象/请求引用，沿用已有工作区显式
  保存、关闭和恢复规则。展示不是新增科学计算，也不是自动保存点。
- 此入口仍只支持 statistics/profile 数值槽。FFT 和图像走既有图像回显，
  晶体比较走既有合格证据入口，不把任意 JSON 当作可显示数值结果。

## 验证范围

新增契约回归覆盖绑定、损坏/不完整输入、草稿竞争、原回执和恢复；
`tests/numeric-presentation-stdio-smoke.mjs` 直接使用完整正式 stdio MCP、
真实 Python provider 和 owned Panel 验证当前 ROI → 测量 → 回显 →
改选重读 → 保存关闭重开。它不是另一个科学服务或模型桥。

本地协议通过不等于原生鼠标键盘验收、外部模型真实接续验收或科学解释
获证。HRTEM/STEM 的成像假设和方法适用范围保持原样。
