# Continue a supplied STEM question using shared objects

Start from the exact saved image/frame/calibration and the expected point,
target and all reference regions explicitly supplied in the question or retained
records. These can arrive directly in Codex; a Panel is not required. Keep the
coordinate source and roles explicit rather than inferring them from a preview.

When the researcher selected them in a retained Panel, read `image_panel_current`.
Its `stem_handoff` carries the exact view, draft, source-frame/calibration recipe,
saved rectangle supports, interaction gate and a source-bound point or line
proposal. Inspect the current image too; the snapshot alone does not establish
visual inspection. Dirty or unknown gates require the existing commit/fresh-read
path, never a guessed coordinate or an old PNG. Other retained windows are not
active scientific inputs.

Ask the researcher only for unresolved scientific choices: which supplied ROI
is the target, which references are intended, acquisition/count meaning, or the
crystallographic projection/registration assumption. Do not infer these roles
from brightness, annotation names, recency or ROI order. User/Agent proposals
are priors. Never snap an expected site to a maximum or invent a measured atom.

Use the exact full source frame/calibration wrapper from `scientific_input` for
`image_statistics` with a fixed target and all explicit same-shape reference
rectangles. Preserve every reference, signed difference, overlap and source text.
`image_profile` samples the original scalar array using explicit source-pixel
endpoints; width-one nearest samples do not prove a dumbbell is resolved.
A crystallographic candidate can motivate these coordinates only with an
explicit projection and image registration; a diffraction match alone does
not supply an atomic real-space registration.

Bind statistics/profiles to the exact candidate with `image_discovery_review`.
`site_context` retains the unchanged expected XY, actual position source,
modality and stored/derived/count meaning. `include_site_continuation` suggests
at most one bounded profile, without dispatching tools or a model. Query original
write IDs after unknown outcomes. CLI `site-followup` prepares linked-review
arguments only from the original review and matching completed profile receipt;
retain all evidence and inspect the actual coverage after the linked review.

S0/raw evidence is sufficient when physical assumptions are missing. Explicit
S2 additionally requires sourced HAADF/ADF modality, an independent-Poisson count
interpretation, fixed 5x5 readouts and 9x9 support, all supplied column centres,
a common width and every requested reference. Normalized abTEM expectation with
no dose/Poisson sampling is not count data; do not convert/round it to fit.
S2 fits conditional amplitudes at supplied centres; it does not locate atoms,
identify elements, determine occupancy, classify defects or certify column-pair
resolution. Keep raw, fitted-total and extrapolated-column observables separate.

Use existing result/export/recovery tools. Numeric tables remain immutable
provider records; no extra Agent runtime or primary chat/log interface is needed.
