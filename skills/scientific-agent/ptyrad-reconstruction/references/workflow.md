# PtyRAD 从原始衍射到一套可用基线

交付一份参数、一次与目标相称的验证，以及仍不确定的量。只按用户授权的范围运行。字段示例以 PtyRAD v1.0.0 为基准，以实际安装版的模板、解析结果和日志为准。 [PtyRAD 运行文档](https://ptyrad.readthedocs.io/en/latest/workflow/run_ptyrad.html) · [完整参数模板](https://ptyrad.readthedocs.io/en/latest/templates/full.html)

## 1. 确认输入和目标

确认用户想看投影晶格、局部界面、逐层结构，还是只验证能否重构。原始 4D-STEM 每个扫描点都有一张二维衍射图。它可以存在于 DM4 数据对象里，也可已无损展开成 HDF5 `[N_scan, Ky, Kx]` 并带扫描顺序和形状。只有导出的二维图、相位堆栈、ADF 图或一张衍射盘时，PtyRAD 缺少重构所需的扫描衍射数据。可先检查图或给参数计划，若需要实际重构则索取原始数据。

只读确认数据对象、扫描快慢轴、衍射轴、扫描形状、采集条件和强度单位。选区用零基、上界不含的原始扫描坐标。需要转换时，保留原始 dtype 与坐标记录，按扫描 x 先变写入 `/dp`，索引 `i=(y−y0)*Nx+(x−x0)`。回读若干分散位置逐像素核对并比较虚拟扫描图。若声称全量无损，逐块比较或校验同一顺序的像素哈希。已核对过的 HDF5 可直接复用。

## 2. 给参数记录来源

查看当前数据附带的记录以及适用的历史结果，给电压、扫描步长、衍射盘心、`dk`、会聚半角、相对旋转／镜像、初始离焦、层数和层间距标出值、单位、来源与适用条件。一张简短表格即可，未影响当前目标的待定项可以保留。

| 来源类别 | 怎么用 |
|---|---|
| 仪器记录或同条件标定 | 核对采集对应、单位、探测器处理和当前盘径。仪器字段也可能来自历史拟合，只在证据适用时采用。 |
| 经验初值或历史参数 | 记录参考样品、采集条件及用途。师兄给的值可以直接作为有出处的候选。 |
| 条件推断 | 记录用到的盘边、已知量、晶面索引或方向对应，以及残差和歧义。 |
| 待定 | 标明缺哪条证据、是否影响当前目标。可用有依据的暂定值试跑时，注明它只支持工作基线。 |

这些类别没有固定优先级。相容且来源清楚的工作参数可以直接复用。遇到冲突，只查会改变基线判断的量。缺绝对标尺时，保留候选并限制量化解释。若某个必填物理量连合理候选都没有，给出所缺的最小输入。

## 3. 用原始盘和同区方向核查几何

**盘心、盘径、尺度。** 在未重采样的原始衍射数据里选代表 ROI，用 `ptyrad_check.py disk` 提取均值盘并拟合盘缘候选。记录像素中心、半径、各 ROI 波动和拟合残差。重叠盘用可见边缘、反向反射或跨区域一致性确认。逐帧质心包含样品散射，整体偏移与逐帧变化应分别检查。拟合用的平滑只作用于分析副本，实际施加的移中心、裁剪和翻转另记顺序。 [盘检查命令](../README.md#从原始-4d-stem-检查明场盘)

对电子 4D-STEM 的小角度关系，使用相对论波长 `λ` 和 cycles/Å 的 `dk`。在 300 kV，`λ≈0.0196875 Å`。`α[mrad]≈1000 λ[Å] R[px] dk[Å⁻¹/px]`，`dk[Å⁻¹/px]=dk[nm⁻¹/px]/10`。盘径只约束 `α/dk`。有可信半角可反推 `dk`，有可信 `dk` 可反推半角。用候选晶面时 `dk≈1/(d·r_px)`，保留索引和间距来源，尽量留额外反射核对。比较两个尺度候选时配对调整半角，使预测盘径与实测盘径相容。 [标定字段与单位](https://ptyrad.readthedocs.io/en/latest/_autosummary/ptyrad.params.init_params.html)

可用 [calibration_math.py](../scripts/calibration_math.py) 复算。下面的数值只演示输入格式。

```bash
python scripts/calibration_math.py --voltage-kv 300 --bf-radius-px 90 --dk-nm-inv-per-px 0.10 --grid 256
```

**相对旋转和镜像。** 在同一扫描 ROI 的 ADF 或虚拟图 FFT 与平均衍射图之间找可追踪的非共线方向，统一坐标的轴顺序、正方向、单位与中心，再用 `ptyrad_check.py rotation` 比较两种手性。FFT 峰方向是条纹法向，FFT 频率间隔取实际扫描步长，衍射向量由反射中心减明场中心。只有无向线时保留 180° 和镜像歧义。再用额外方向或另一 ROI 核查。晶带轴、仪器角标签和相对旋转分别记录。证据只支持少数候选时，固定同一 `dk/α`、离焦、输入和模型，在同 ROI 检验这几个候选。缺方向证据时，报告方向未定，身份变换可作为注明假设的试跑起点。 [旋转诊断命令](../README.md#比较扫描旋转和镜像候选)

在使用版本里核对 `meas_flipT`、`pos_scan_flipT` 和 `pos_scan_affine` 的轴与顺序。用不对称标记检查正负号、翻转后中心和窗口。偶数网格的几何中心与 FFT 原点可能不同，翻转后核对是否引入一像素偏移。转换和 YAML 对同一次操作只应用一遍。 [PtyRAD 几何字段](https://ptyrad.readthedocs.io/en/latest/templates/full.html)

## 4. 配一套基线并短跑

复用适用于当前数据的有效 YAML，或从安装版官方模板复制一份。填写数据键、扫描形状和步长、标尺和孔径、已选几何、初始探针、网格、层数、损失和更新计划。投影目标可先用简单模型，深度目标使用足够的切片。已有可用离焦初值就固定它。没有实测值时可采用有出处的工作值，采用近焦假设时也可暂用 `C10: 0` 并标明依据。只有探针波前或 Z 分配出现疑点时才追加离焦对照。v1 电子分支用 `C10=-defocus`，正 `C10` 表示过焦，字段单位 Å。 [PtyRAD 参数模板](https://ptyrad.readthedocs.io/en/latest/templates/full.html)

短跑选择覆盖目标结构与扫描重叠的代表区域，保存至少一个完整检查点。保留有效 YAML、版本、输入指纹、ROI、轮数和执行日志。环境或数据读取路径新建时，可用官方小样隔离安装问题。已有可读结果和匹配评价时可直接用已有证据。以下命令用于已经准备好的配置。

```bash
python -m ptyrad --help
python -m ptyrad validate-params params/roi.yaml
python -u -m ptyrad run params/roi.yaml --gpuid 0
```

发现具体问题时，只加能区分当前假设的一组或少数配对。对照固定原始输入、物理 ROI、轮数、初值和其他训练条件。比较 PACBED 时保持微批大小及分组，因为它对微批内的衍射图取平均。把昂贵的全幅、扩网格和较长迭代留给明确的研究需要。 [按症状选诊断](diagnostics.md#按症状选对照)

当全幅层间结构关系影响研究结论，且小区无法代表各区域时，可先用基线跑一小段全幅并保存多层检查点。只有同一结构在多层可稳定匹配时，才由上至下的横移估计整体倾角，再用小区固定倾角配对决定是否用于全幅。已有可分析的多层检查点可以直接用。若短跑切片信号不足，保留倾角待定，按研究目标决定是否继续基线。 [按需估计和验证对象倾角](diagnostics.md#按需估计和验证对象倾角)

## 5. 验收到研究目标即可停

满足以下条件即可交付可用工作基线，记录未确认的物理量。

- **输入与运行。** 源对象、扫描／探测器轴、变换和强度处理均有记录。试跑的损失、关键张量和需要恢复的状态为有限值。目标保存点完整可读，内部轮次、形状和输出一致。
- **结构。** 在同一物理 ROI、层位和色标下，研究所需的界面、晶格方向或深度对比可辨，未发现足以推翻当前用途的边缘、条带或层间假象。主张结构稳定时，再用后一个检查点或独立区域核查。只做过通路短测时，报告通路验证。
- **前向拟合。** 用同一组测点、有效探测器窗口和归一化，对照单点、位置平均衍射图和残差。可报告振幅 NRMSE、强度相关和预测／实测总强度比，另报等总强度时的图样残差用于区分尺度偏差与图样偏差。注明哪些点参与了训练。相位更锐、训练 loss 更低都不足以单独证明物理可靠。

有实际阻碍再升级。输入不一致或盘心、尺度、方向仍冲突时回查几何。相位与衍射结论矛盾时增加一个针对性对照。数值异常先定位首个坏更新。研究目标要求绝对尺寸、材料身份或深度分辨率时，补独立证据。满足当前用途后保留参数和待定项，结束搜索。 [数值、分箱与接续诊断](diagnostics.md)

**交付。** 给出有效 YAML、检查点、代表相位／前向图、证据范围和下一项仅在何种现象下需要。分析用相位 TIFF 保留有符号 float32。PtyRAD v1 的 `result_modes.bit: [raw]` 保留数值，`['32']` 会归一化。回读验证像素值、`ZYX`、XY 像素尺寸、Z 层距和 rad 单位，物理尺度从相应检查点取得，Å 除以 10 得 nm。无独立绝对标尺时注明导出尺度采用的工作假设。 [PtyRAD 输出 HDF5](https://ptyrad.readthedocs.io/en/latest/workflow/read_ptyrad_output_hdf5.html) · [结果格式](https://ptyrad.readthedocs.io/en/latest/walkthrough/13_results_figures.html)
