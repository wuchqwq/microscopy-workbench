# PtyRAD 针对性诊断

只读和处理当前症状有关的部分。一次选择能改变决策的检查或配对。基线的相位与前向表现已满足研究目标时，保留现有配置。 [基线和验收](workflow.md)

## 按症状选对照

| 现象 | 优先核查与比较 |
|---|---|
| 晶格只剩一个方向，或界面相对扫描坐标扭曲 | 先核原始盘心、标尺、扫描步长和变换方向。角度仍有歧义时，只比较有方向证据的候选。 |
| 晶格聚在模型首尾，或相邻层几乎相同 | 分开核查离焦初值、模型深度、层间距和 Z 平滑。按相同物理深度比两条晶格频带、相邻层和首尾残留。`std×dz` 是 Z 高斯的物理宽度参数。层数和层距描述模型采样与覆盖，真实厚度需另有依据。 |
| 同一晶粒的晶柱随 Z 有一致 XY 漂移 | 用可分析的多层检查点按下文估倾角，再看固定倾角能否减少残余漂移并保住前向拟合。 |
| 晶格变锐，预测衍射偏暗或残差偏向某个角区 | 同时看总强度比、匹配强度后的形状误差、盘内外残差和复探针。先选一项检查归一化、探针或损失。改变损失定义后用共同的前向指标比较。 |
| 中心可用，边缘或局部扫描可疑 | 扩真实扫描上下文，在同中央 ROI 复评。怀疑扫描漂移时，比较固定与可动位置，检查实际位移的大小和空间分布。 |
| 计算负担过大 | 先用代表性物体尺寸和实际模型测初始化、稳态轮时、保存时间和峰值显存。比较加载方式、微批与累积、网格或编译时保持其他因素可解释。涉及不同观测窗口时按下文比较。 |

探针模式表示混合照明。一个对象也可以包含多个空间区域或物相。评估复探针时看模式功率、孔径外能量和前向残差。`loss_single.dp_pow=0.5` 比较振幅，`0.3` 压缩强弱差更多。Poisson 型项与 PACBED 可配合使用。提高某一频带功率可能伴随强度拟合变差，比较时保留同尺度切片和共同评价窗口。 [PtyRAD 探针、损失及约束](https://ptyrad.readthedocs.io/en/latest/templates/full.html)

## 按需估计和验证对象倾角

对已有相位堆栈，用 `ptyrad_check.py tilt` 测逐层位移和斜率。保留每个 ROI 的配准质量和候选状态。 [相位倾角命令](../README.md#从已有多层相位测倾角)

1. **看切片能否用于测量。** 读取已保存的多层有符号相位、实际 `dx` 和层间距。必要时用全幅基线短跑取得检查点。先在几个含同一晶粒且避开边缘的 ROI 检查相邻层和较远层能否跟踪同一晶柱或哑铃。只有配准方向、位移和线性斜率在多个窗口及合理频带下可重复，才给固定倾角候选。弱对比、重复周期错配、不同晶粒或弯曲都可使一个全局值失去代表性。作者的流程以可分析的多层重构为前提。 [作者建议](https://github.com/chiahao3/ptyrad/issues/10#issuecomment-3006142815) · [官方局部倾角工作流](https://ptyrad.readthedocs.io/en/latest/workflow/get_local_obj_tilts.html)
2. **从真实横移换算。** 在原生对象数组 `[y,x]` 下测同一结构从浅层到深层的位移 `Δr_px = r_bottom − r_top`，通常 `+y` 向下、`+x` 向右。若配准函数返回“把深层移回浅层”的对齐位移，取负才是结构的实际横移。先用已知位移的小数组核对函数符号。可用相邻层位移累计并拟合横移随 Z 的斜率，用隔层配准和其他窗口检查周期跳峰。均匀层距下 `Δz=(k_bottom−k_top)×dz`，以层中心间距计算。用同一长度单位乘 `dx`，按分量计算 `θ_yx[mrad] = 1000×atan(Δr_px×dx/Δz)`。拟合斜率时先把 pm/nm 除以 1000 得到无量纲斜率。 [官方位移及角度定义](https://ptyrad.readthedocs.io/en/latest/workflow/get_local_obj_tilts.html#plot-the-position-dependent-tilt-vectors)
3. **确认角度是残余还是总量。** 先查源检查点实际的 `obj_tilts`，包含已施加的值。零倾角基线测得的位移可用于估计总量。已有固定倾角时，测得的是当前模型中的残余斜率。在相同对象坐标、深度方向和小角度模型下，可按分量把残余斜率加到 `tan(θ旧)` 再反算总角，并通过配对验证。对象 `y/x` 是模型数组的行／列，跟扫描快慢轴、界面显示轴或物理 beam tilt 各有不同。若更改扫描旋转、镜像或导出方向，用对应结构验证新旧对象坐标的线性映射，将物理位移向量按其线性部分转换，再换算角度。仅改了 `pos_scan_affine` 数字时，不能据此自动旋转倾角向量；坐标映射不清楚就从新检查点重新测。 [作者对轴和扫描仿射的说明](https://github.com/chiahao3/ptyrad/issues/10)
4. **先做固定倾角小区对照。** 在相同物理 ROI、源数据和额外轮数比较原模型与估计角。记录两组初始化方式。重用旧检查点时，改变传播器也会改变模型表示，需要核对层的反向位移、入口探针补偿和变换前后的前向，避免把显示对齐当作重构修正。比较固定倾角组的残余斜率、同色标切片／投影、共同实测窗口的前向误差与强度比。只有结果对当前目标有收益且范围内一致时才考虑应用到全幅；局部差异大时保留区域结论。对象倾角作用于层间传播，beam tilt 改变入射波并可能影响像差，扫描位置修正则改变各测点的入射坐标。 [作者的固定倾角建议](https://github.com/chiahao3/ptyrad/issues/10#issuecomment-3006142815) · [对象倾角的建模范围](https://ptyrad.readthedocs.io/en/latest/workflow/get_local_obj_tilts.html#notes-about-object-tilt)

以下是 v1 固定全局倾角的 YAML 片段，数值只演示 `[y,x]` 和 mrad 的写法。把字段并入基线，保留其他更新设置。单对象模式将 `loss_simlar.state` 设为 `false`，即便有多个探针模式或多层。该项跨对象模式求标准差，与倾角修正无关。

```yaml
init_params:
  tilt_source: simu
  tilt_params: {tilt_type: all, init_tilts: [[2.0, -5.0]]}
model_params:
  update_params:
    obj_tilts: {start_iter: null, lr: 0.0}
loss_params:
  loss_simlar: {state: false}
```

**AD 优化留作有依据的后续对照。** v1 的非零初始倾角会在固定模式下生效。梯度更新还需要 `model_params.update_params.obj_tilts` 的有效 `start_iter` 和正学习率 `lr`。源码在 `start_iter` 当轮启用，`end_iter` 当轮关闭。应在目标轮次之前留出评估段。先核对解析后的调度、参数形状和真实更新记录，再讨论学习率。`tilt_type: all` 只给一个全局向量。需要位置相关时，检查 `each` 或文件输入的每点 `[y,x]` 是否与扫描索引一致，并以已有局部证据初始化。v1 逐点倾角会分配随扫描点数增长的传播器缓存，适合先在 ROI 检查。源码将倾斜 Fresnel 近似的适用量级写为约 1°／17 mrad，接近或超出时需额外验证。 [作者的 AD 参数说明](https://github.com/chiahao3/ptyrad/issues/10#issuecomment-3006142815) · [PtyRAD 倾角参数](https://ptyrad.readthedocs.io/en/latest/_autosummary/ptyrad.params.init_params.html)

## 编译或反传出现非有限值

1. 找到最后一个完整可读且有限的检查点。确认对象幅相、复探针、位置、活动优化器动量和步数。区分日志的最后进度和已持久化的进度。保留原件。
2. 找最早出现异常的位置。在每次实际优化器更新前，核对当前累积窗口的前向、损失和全部活动梯度是否有限，记录绝对轮次、更新序号、批次顺序、扫描索引和环境。`linalg.eigh` 等下游报错时，也要检查传给它的探针是否已含非有限值。
3. 对可疑窗口，用同一个更新前的模型、优化器状态和随机状态重放。保持微批顺序、累积除数、精度和算子输入一致。丢弃本窗口的坏梯度与临时缓存，重放完整窗口。普通 eager 是关闭编译的路径。若 eager 通过，可用 `aot_eager` 与 `inductor` 进一步缩小范围。只有同输入、同状态的差异才能支持编译路径相关的判断。
4. 用 eager 继续或用经过验证的守卫时，只在该次梯度检查通过后执行一次更新。遇到更新后状态异常、eager 仍异常或无法复现原始状态时，保留诊断日志并停在可恢复点。保存新检查点后回读关键张量、动量有限性、步数和前向。守卫只在需要时采用，运行到某轮的日志需要与检查点一起验收。 [PyTorch 编译排查](https://docs.pytorch.org/docs/2.7/torch.compiler_troubleshooting.html)

## 分箱、模拟裁剪和补零

**分箱改变采样。** 对探测器两轴做 `b×b` 块求和，选择不溢出的累加和输出类型，保持扫描顺序。完整覆盖且未裁边时逐帧总强度应保留。倒空间步长 `dk_new=b*dk_old`。以零基像素中心计，分箱从索引 `x0` 起时 `cx_new=(cx_old−x0−(b−1)/2)/b`，Y 同理。核对实际边界、掩膜、中心和半径。分开记录文件原标尺和分箱后工作标尺。对固定倒空间步长、模拟后裁剪的路径，`dx=1/(Nsim*dk)`。`dx` 相同仍可能有不同的波传播窗口和实测倒空间采样。

**两种观测假设。** `simu_match_mode: crop` 可把较大模拟图裁回实测窗口再算损失。若在实测图外补零并把外圈纳入损失，相当于额外约束外圈预测接近零。按相同实测窗口和扫描点评估两者。需要跨分箱前后比较时，对预测和测量使用同一块求和和掩膜。另核归一化分母、强度单位及实际启用的损失，窗口变化可能改变各项权重的相对作用，按安装版本验证。 [PtyRAD 网格、补边与匹配参数](https://ptyrad.readthedocs.io/en/latest/templates/full.html)

## 跨网格热启动与同网格恢复

- **跨网格热启动。** 用已保存的对象、复探针和位置作为新模型的初值。先核对扫描点和物理坐标、方向、层距、探针模式、`dx` 和新旧原点。确有相同采样及整像素映射时可以裁剪复制，否则需要明确的物理坐标变换和验证。核对变换后的幅相、探针功率、位置修正和共同窗口的初始前向。用新的优化器状态与本地轮号，保存来源检查点和变换。即使 `dx` 恰好相同，数据分箱或模型窗口变化也会改变优化问题。
- **同网格恢复。** 核对数据和选点、网格、坐标、有效模型、实值相位、复探针及位移。校验优化器状态、参数组、有限值和步数。使用调度器或其他训练状态时一并核对。用可验证的绝对轮次恢复方式，或明确记录 v1 原生局部轮数到累计轮数的映射，并同步更新、约束和保存计划。以内部 `niter` 和已保存状态为准。普通初始化可能重新变换位置或折回相位，须验证恢复后零更新状态。 [PtyRAD 载入已有重构示例](https://ptyrad.readthedocs.io/en/latest/walkthrough/04_resume_reconstruction.html)

训练完成后的导出或评价失败时，可从已验证的检查点补做对应步骤。更新后另存新路径，避免覆盖恢复起点。
