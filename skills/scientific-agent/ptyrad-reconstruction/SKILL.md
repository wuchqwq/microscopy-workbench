# PtyRAD 4D-STEM 重构

目标是交付一套满足研究用途的工作基线。在用户授权范围内实际检查数据、准备配置、试跑并验证结果。盘检查、旋转候选和层间位移都用 [README 中的 CLI](README.md)，人工复查沿用相同命令。

- **先确认数据和证据。** 使用[最短工作流](references/workflow.md)。重构需要逐扫描点的衍射数据。把仪器、经验和历史参数当作带出处的候选，用当前数据确认适用性。盘径约束 `α/dk`。相对旋转另查同一 ROI 的扫描图和衍射图方向对应。
- **用一套参数试跑。** 复用适用基线或从当前证据选一套初值。只在具体症状影响结果时增加少量对照。离焦有可用工作值时可以固定。用可回读的有限值检查点、同 ROI 相位和共同窗口前向残差判断是否满足目标。基本可用即可交付，注明待定量。
- **按需做倾角修正。** 如果逐层结构有一致的横向漂移，先从可分析的多层检查点估计倾角。需要了解全幅不同区域时，可先短跑全幅并检查切片是否足以配准。用估计的固定倾角做小区配对，结合残余位移和前向拟合决定后续。见[倾角流程](references/diagnostics.md#按需估计和验证对象倾角)。
- **有具体问题再深入。** 对编译反传异常、分箱或跨网格热启动与同网格恢复，按[针对性诊断](references/diagnostics.md)选对应部分。标尺换算可用 [calibration_math.py](scripts/calibration_math.py)。
