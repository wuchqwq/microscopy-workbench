# External method sources and conventions

Accessed during this review on 2026-11-01. These are method/implementation sources, not certificates of this project's correctness. Installed dependency versions are captured in [python-freeze.txt](evidence/python-freeze.txt). No third-party implementation is used as an unconditional numerical oracle.

| Area | Primary/official source and version | Applicable convention and comparison boundary |
| --- | --- | --- |
| A: finite Fourier transform | [NumPy 2.4 DFT manual](https://numpy.org/doc/2.4/reference/routines.fft.html), implementation-details equations | Negative forward exponent, unnormalized forward sum, linear cycles frequency, separate odd/even Nyquist ordering. Runtime NumPy is 2.5.4, not the manual version. We verified actual output against independent explicit finite sums for every bin; version similarity is not the proof. Real-input conjugates carry dependent information. |
| A: window | [NumPy 2.4 hanning](https://numpy.org/doc/2.4/reference/generated/numpy.hanning.html) | Symmetric window `0.5−0.5cos(2πn/(M−1))`, not periodic `M` denominator. Worker subtracts raw mean before weighting, so weighted DC need not be zero. We compute the formula independently; windowing changes leakage/support rather than adding resolution. |
| A: extrema | [SciPy 1.18.0 maximum_filter](https://docs.scipy.org/doc/scipy-1.18.0/reference/generated/scipy.ndimage.maximum_filter.html) | Neighborhood maximum and boundary mode are numerical operations, not a scientific peak significance test. Runtime SciPy1.18.1. The impulse counterexample follows analytically from a flat-modulus DFT; it is not a disagreement with maximum_filter's documented behavior. |
| B: Gaussian image derivatives | [SciPy 1.18.0 gaussian_filter](https://docs.scipy.org/doc/scipy-1.18.0/reference/generated/scipy.ndimage.gaussian_filter.html) | Positive `order` differentiates a Gaussian; axes are array order `[y,x]`. Code uses reflect boundaries, derivative sigma1, tensor sigma min(window)/8, truncate4. These lengths are image pixels, not calibrated physical directions or material strain. |
| B: structure tensor | [scikit-image 0.25.2 structure_tensor](https://scikit-image.org/docs/0.25.x/api/skimage.feature.html#skimage.feature.structure_tensor) | Locally weighted gradient outer products and explicit `rc/xy` ordering provide method context. Code uses its own Gaussian-derivative construction and heuristic scoring, not an identical call to this implementation. Scores .5/.3/.2, threshold .18 and lag floor .15 have no demonstrated statistical calibration. Installed scikit-image0.26.0 is used for GPA unwrap, not this discovery tensor. |
| C/D: GPA phase | [Hÿtch, Snoeck & Kilaas, Ultramicroscopy74 (1998),131–146](https://www.sciencedirect.com/science/article/pii/S0304399198000357), DOI10.1016/S0304-3991(98)00035-7 | Fourier-component phase and displacement relation. Publisher abstract/introduction/equation snippets accessed; full subscription paper was not independently reproduced. Repository uses `P=−2πGu_E`, explicit XY vs array YX, and a separately derived finite Eulerian `F=(I−grad u_E)^−1`; do not attribute that full finite implementation to unseen paper text. |
| C: unwrap | [Herráez et al., Applied Optics41 (2002),7437–7444](https://opg.optica.org/ao/abstract.cfm?uri=ao-41-35-7437) | Original reliability-based noncontinuous-path unwrap method. Current code invokes scikit-image0.26.0 masked unwrap with explicit deterministic RNG. Analytic probes test admitted outputs; noise-dependent failure rates remain NOT_TESTED. |
| E: occupancy parsing | [libAtoms extXYZ specification/parser](https://github.com/libAtoms/extxyz) | `Properties` can carry per-site arrays, as actual ASE3.29.0 parsing independently confirms. General specification was accessed, not a pinned extXYZ package execution; repository's actual parser is ASE. A custom array is scientifically explicit even if the downstream implementation does not support it. |
| E: occupancy / structure factors | [IUCr occupancy definition](https://www.iucr.org/__data/iucr/cifdic_html/3/CORE_DIC/Iatom_site.occupancy.html), [IUCr International Tables structure-factor section](https://onlinelibrary.wiley.com/iucr/itc/Cb/ch6o1v0001/sec6o1o1o7/) | Occupancy is the site fraction, not an arbitrary display property. E-01's `1−occ₂` result is a directly evaluated two-site phase sum. It requires no agreement with a separate diffraction simulation. |
| E: reciprocal centering / twin operation | [IUCr integral reflection conditions](https://dictionary.iucr.org/Integral_reflection_conditions), [IUCr twin law](https://dictionary.iucr.org/Twin_law), [Cayron2007](https://journals.iucr.org/a/issues/2007/01/00/au5046/index.html) | Centering conditions and symmetry-equivalent orientation operations; chemical basis/intensity formation remain separate. Tests use independently specified F[001] vectors, a two-site HCP complex sum, and an exact Rodrigues matrix. |
| E: simulation | [diffsims generator official documentation](https://diffsims.readthedocs.io/en/latest/reference/generated/diffsims.generators.diffraction_generator.DiffractionGenerator.html), installed **diffsims0.7.0** | `latest` documentation is not treated as version-pinned. Installed0.7.0 generator source/path/SHA was inspected and recorded in [installed_dependency_source.json](evidence/astra/installed_dependency_source.json). Voltage, excitation, atomic factors, orientation and cycles/Å must agree before interpreting differences. No dynamical-scattering or real-image-transfer validation follows. |

F (evidence combination) has no external theorem certifying these custom heuristics. The reviewer inspects actual source dependence and independent countermodels. D-01 uses the fact that a smooth linear phase ramp has zero closed-loop circulation; this is why two overlapping filtered observations cannot become new independent reflection evidence merely because their demodulation centers differ.

The analytic alias, impulse, quadrature-contrast and opposite-vortex examples are direct mathematical counterexamples. They do not need a mature package to declare their truth. Independent matching uses exhaustive enumeration of a finite assignment problem instead of comparing two wrappers around the same SciPy solver. Apparent library disagreements are first checked for sign, axes, normalization, units, finite-vs-infinitesimal strain, and selected reflection identity.
