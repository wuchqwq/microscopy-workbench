## 2. 算法地图：哪些是观测，哪些是条件

| 链路及源码入口 | 输入观测 → 处理 → 中间量 / 输出 | 外加假设 / 先验 | 下游允许的使用与本轮覆盖 |
|---|---|---|---|
| `image_workspace` open/frame/calibrate/fft/measure | 原始像素+ROI → 显式去均值、无窗口 FFT、DC 到峰坐标 → cycles/pixel 或标定后的倒易向量 | 图像域声明、DC、signed XY 标定和峰位置来源；坐标可由人工选择 | 输入数值不是晶体身份；本轮完整走保存对象、标定、测量和重载 |
| `structure_tools` open/orient/simulate | CIF 晶胞/原子模型 → ASE、显式取向、diffsims 0.7.0 → HKL、未光栅化倒易坐标、运动学强度 | 候选结构、占位、取向、200 kV、激发误差与截断范围都属于模拟条件 | 模拟预测不是实验观测；核对两套非平凡取向的解析坐标，不认证 HRTEM 或动力学强度 |
| `registration_proposal.propose` | 已测向量+指定 HKL 对应 → 只用 fit 部分做 proper SO(2) → 角度、残差、held-out 状态 | scale=1、DC 平移=0、屏幕奇偶显式；对应关系是用户断言 | 检验固定对应的几何一致性；新增亚频率格伪 held-out 反例 |
| `reflection_compare.compare` | 同一观察表+固定配准+候选反射 → 有界一对一匹配 → 匹配、未匹配、歧义 | 残差容限是用户声明，不是误差 SD | 不把重用同一 FFT 当新证据；保存配准绑定到原模拟对象 |
| `general_evidence` / `twin_tools` | 两域测量+有限候选+共同变换 → 方向族/质量准入 → compatible / incompatible / insufficient | twin 另有支持晶体基元、指定关系和界面迹线；没有全局候选完备性 | 正例、错误候选/迹线、错标定、缺标定、单 Friedel 族及冲突恢复均走真实 worker；独立验证仍 `NOT_VALIDATED` |
| `image_gpa_core.analyze` | 无窗口实图 FFT+两条非共线 g → 截断 Gaussian 带通、相位/解包裹、连通参考 → u、F、Green strain、rotation、mask | 单域投影图像晶格、相位来自位移；参考和频带外加；物理张量需要 signed XY 度量 | 本轮解析非均匀场、带宽、双周期叠加、纯噪声、参考断裂；不是材料应变认证 |
| `geometry.measure_geometry` | 中心/点坐标+标定+可选 SD → 长度/角度及一阶传播 | 点误差独立；XY 标度误差独立，但中心和标度在多个点间共享 | 20 万次独立向前采样核对；未知项维持 UNKNOWN；不能表示任意相关标定 |
| `image_domain_compare` | 保存 ROI 峰族 → 显式有限 SO(2) 比较 → 描述性关系 | 标定/有限角集合/阈值，不含统计置信度 | 重现第一轮 A02：缺物理标定被误写为 incompatible；未重做结构域发现与主动策略收益评估 |

原始像素和用户标定分别是观测与外加条件。Fourier 峰/几何相位是处理后的图像信息。
HKL、模拟衍射、指定孪晶关系是候选产生的信息。所有“compatible”均受以上条件限制，
不能推出唯一物相、三维 Burgers 矢量、原子界面相干或三维结构。

## 3. 按风险排列的发现与反例

### R2-C1 / P2：亚分辨观测可通过 held-out validation 字段

分类 **2 方法边界 + 4 输出语义风险**，不是已证实的 SVD 数学错误。
位置：`crystallography/registration_proposal.py:222–265` 的重复/共轭/ULP 筛选，
`:288–310` 的状态，`crystallography/structure_tools.py:708–711` 的比较传播。

最小构造：tetragonal `a=b=4 Å,c=20 Å`，zone `[0,1,32]`，平面转角 17°；
128² 实图只有 `(0.25,0)`、`(0,0.25) Å⁻¹` 两个余弦族，0.5 Å/pixel。
fit 指定 `(100),(010)`，在第一峰附近另存一个测量坐标并声明为 held-out `(101)`。
两位置只差 `0.000312493896663 Å⁻¹ = 0.0199996094 FFT bins`。
这里没有独立生成的第三个观测峰；新坐标来自故意错误的用户对应断言。

实际：角度 17°，held 残差 `1.39e-17 Å⁻¹`，
`validation_status=held_out_geometry_consistent`，`held_out_validation_passed=true`，
`unresolved_binary64_aliases=[]`；每个观测仍保留五个容限内候选，比较继续传播 true。
近共轭 `(-101)` 同样通过，精确 Friedel `(-100)` 则正确拒绝。

预期的科学结论：只能说指定坐标/对应残差一致；独立峰支持应未判。
源码本来就明确“不证明统计独立或实验分辨率”，不能说它承诺了峰检测认证；
风险在于显著的 pass 布尔值比实际观测契约更容易被下游误读。
**不能**把 1 ULP、匹配容限或 1 FFT bin 任取一个当作通用分辨率阈值。
建议先设计观测峰/分辨组身份、残差一致性与独立性分离，以及显式版本迁移。
完整原请求、测量 ID、数据哈希和原输出见 [独立反例](crystal/REVIEW.md)。

### R2-A02 / P2：缺标定被解释为不相容（第一轮问题重现）

分类 **4 输出解释过强**。位置：`tools/image_domain_compare.py:vectors_in_domain`
第 65–75 行正确发现标定不可用；`_entries` 第 270–271 行把它写成 incompatible；
`derive` 第 301–306 行继续输出 incompatible。

最小构造：64×160 图像 `2cos(2πx/8)+cos(2πy/8)`，选两个不相邻 64² ROI，
角度 `[0]`，容限 `.001`。pixel 比较得到 compatible_signature；同一观测请求
physical 比较、没有长度标定，实际得到 incompatible 且没有候选。
预期应为 not_comparable / insufficient_evidence；没有物理度量无法排除相容性。

这不是新的发现；[原输出](evidence/missing-calibration-original-comparisons.json)
保留旧状态及请求。general/twin 的缺标定控制则正确 insufficient_evidence，
不能把局部链的问题归罪于所有比较模块。
建议单独版本化修订：旧报告继续按旧算法校验，新请求使用新的未判语义。
`validate_references:387` 会重算旧报告，所以简单改字符串会破坏历史对象，不能就地替换。

### R2-G1 / P2 使用限制：GPA 数值有效不表示晶格/位移模型成立

分类 **2 方法局限 + 3 数据不适用**；现有源码明确写 hypothesized，未发现这里谎称
材料应变已验证。位置：`tools/image_gpa_core.py:205–280` 的振幅/相位残点/参考准入，
`:288–304` 的可逆性与张量 mask，`:347–351` 的限制；`tools/image_gpa.py:25–32`。

两个独立反例，固定 `g=((.125,0),(0,.125))`、σ=.018、参考 `[92,92,116,116]`：

1. `cos(2π·.125x)+w cos(2π·(.125+1/256)x)+cos(2π·.125y)`，256²。
   这是声明的两个静止、不同周期载波叠加模型，模拟未变形投影层的混合，
   不是实际样品分层观测；不存在唯一的单域位移真值。
   w=.8 时计算的 Exx 范围约 −1.32% 到 +13.31%；w=1.2 时约 −15.92% 到 −1.66%。
   每例 61.0% 图像像素具有 valid_tensor。它们是 beat 相位梯度，不能归属任一层的应变。
2. 标准正态噪声，固定种子 0…19，全部能计算 hypothesized 场，valid_tensor 比例
   36.8%…51.5%；seed 0 的 |Exx| 第 95 百分位约 .2502。
   seed 0 也走 open→frame→fft→gpa 保存链，原始输出和数组哈希均保留。

这个 20/20 是固定玩具输入的**计算完成率**，不是实验假阳性率，也没有自动证明
GPA 错算。它证实相对振幅门槛和连通 mask 不是 SNR/单域证据。
建议保留研究工具，但上游单域、成像模型和参考不成立/未知时，物理解释必须未判；
不能为了拒绝这 20 张图而后验调阈值。

### R2-G2 / P2 使用限制：密集输出可能完全漏掉带外应变变化

分类 **2 方法局限**，不是导数实现错误。位置：`image_gpa_core.py:191–198` 的
3σ 带通截断、`:282–287` 的位移/梯度。独立真值：
`u_x=.1 sin(2πkx),u_y=0`；`Fxx=1/(1−.1·2πk cos(2πkx))`，`Exx=(Fxx²−1)/2`。
观测图像直接以 `cos[2π·.125(x−u_x)]+cos(2π·.125y)` 生成。

| k / σ (cycles/pixel) | 解析 Exx RMS | 测量/真值 RMS 比 | 判断 |
|---|---:|---:|---|
| 1/256 / .018 | .00173009 | .976702 | 缓慢场误差与带通预期一致 |
| 4/256 / .018 | .00694357 | .685045 | 仍有效，但幅度显著衰减 |
| 8/256 / .008 | .01389656 | 5.32e-13 | 主要应变边带在 3σ 外，输出几乎零 |

三个例子中心区域都有 16,384 个 valid_tensor 像素。最后一个算得出零应变场，
不能据此断言没有短尺度应变。Gaussian 未截断小相位传递与本实现的 3σ 截断已区分。
建议记录带宽/参考敏感性，输出分辨率范围；不要把逐像素采样或扫描步长当物理分辨率。

### R2-U1 / P2 使用限制：误差模型与未判阈值之间尚无统计闭环

分类 **2 已声明模型局限 + 5 证据不足**。位置：`crystallography/geometry.py:104–175`，
`registration_proposal.py:137–171`，`reflection_compare.py:251,349–364`，
`general_evidence.py:122–161`。已有 SD 不是随后匹配容限的自动统计依据。

已核查合理：在声明的独立点、独立 XY 标度、共享中心/标度模型下，200,000 次直接
随机前向采样的 d、角度 SD 与一阶式最大相对差约 .241%；缺中心 SD 时仍 UNKNOWN。
没有发现漏算共享中心协方差。

反例一：两向量 `(10,10),(10,−10)`，仅有共同 1% 各向同性标度误差时夹角严格不变。
当前接口只能输入各轴独立 SD，把两个 .01 填入得到 .810285°。
这是使用了错误输入误差模型，**不是**实现违背其声明；需要共同模式/协方差表示。
反例二：接近平行的 `(100,0),(200,0)`，独立 y SD=.1，线性未折叠角 SD=.064059°，
真实非负夹角采样 SD=.038617°，均值=.051171°。输出已写 unreliable_at_0_or_180，
不能把这个 SD 直接当对称置信区间。

配准明确 equal weight、无统计不确定度；general/twin 的方向分组半径明确是确定性
容限。正确做法是继续把 compatible 当条件几何判断；在要宣称材料结论的层面，
误差未知、候选歧义或证据质量不足时维持未判。
补充固定数据扫描：10% 错误采样尺度的最大真对应残差为 `.0603022689 Å⁻¹`。
预先声明容限 `[.003,.03,.06,.061,.08] Å⁻¹`，general 正确候选对的状态依次为
不相容、不相容、不相容、相容、相容；错误 parent/parent 替代始终不相容，
每侧四个方向族始终不变。这里没有改观测或后验选“最佳容限”；这说明通过条件
可随容限改变，不能把宽容限相容当作标定正确。twin 反射关系也跨越该边界，但
此控制不提供界面迹线，所以总体仍 insufficient_evidence。
本轮未建立实验 SD、覆盖率、假阳性/漏检率，也未验证任何“95% 置信”含义。

## 4. 已核查合理的设计

- 非零 23° 旋转及 signed anisotropic sampling 的完整候选链按手写矩阵得到正确
  倒易坐标；改变 held-out HKL 不改变 fit 角度，并使验证失败。未发现该例的拟合泄漏。
- scale=1、translation=0；错误尺度不靠重新拟合挽救。保存配准不能挪用到另一模拟，
  旧测量/配准不能冒充重标定后的测量。正交 SVD 的 proper rotation 约束符合目标。
- 正确 parent/twin 候选条件相容、parent/parent 错误替代不相容；错误 90° 迹线使
  迹线/总体不相容，但不改写本来相容的反射关系。没有把不一致悄悄平均掉。
- general/twin 对缺标定、一条 Friedel 方向族和歧义保持不足；多个有限候选不推出唯一相。
  未匹配模拟反射保留在报告中。实空间 FFT 不能用衍射模拟强度作直接定量解释。
- 无 held-out 时状态 not_tested、pass=null；精确重复、精确 Friedel 和退化 fit 正确拒绝。
- GPA 非均匀慢变场的**完整保存链** Exx 最大绝对误差 `5.69e-5`，signed XY 标定
  被携带并正确标为物理坐标；该对角例本身不验证符号变换。非对角张量/转动的 signed
  XY 变换另由本轮运行的既有 `test_image_gpa_core` 和 `test_image_gpa_physics` 覆盖。
  断开的参考分量被排除；参考同时跨两个不连通有效分量时 `GPA_REFERENCE_INVALID`。
  `fixed_g` 只固定相位常数规约；`fit_reference` 去掉参考平面/均匀参考变形，只有相对意义。
- 原请求 ID 冲突被拒绝，原 journal 哈希不变，result 查询恢复原对象。
  相同 FFT 的 measurement、registration、comparison 是同一证据链，不能相乘当多份独立证据。

## 6. 最优先的三项工作

1. **先闭合证据身份与未判契约。** 将 correspondence residual、源峰独立性、
   方向新信息、统计/外部验证分层；解决 R2-C1 和 A02，并设计旧对象只读兼容。
2. **再资格化 GPA 的适用范围。** 固定带宽/参考/单域扰动矩阵和独立验证集，
   报告空间传递与模型敏感性；明确 noise/mixed-domain 结果为何不能解释成真实应变。
3. **建立测量到判断的误差预算。** 从点、DC、共同标定和畸变协方差出发，
   检验保守未判规则的覆盖率与误报/漏检；与简单固定流程比较后再增加主动策略复杂度。

## 7. 对当前可信用途的直接回答

**哪些任务上可信：** 有明确 ROI、来源/单位/坐标约定的图像周期和倒易几何测量；
在固定候选、标定和配准条件下检验投影反射是否相容；在本轮受控单域、慢变合成条件下
提取相对投影位移/应变。可信范围是这些已验证的计算和条件，不能扩展成真实材料准确率。

**哪些条件应未判：** 缺失或可信度不足的标定/参考、未分开的峰或投影、歧义赋值、
不足的独立方向、跨域/叠层、低信噪比、带外变化、未知误差或相互冲突的证据。
数值可保留为诊断，但相应物理结论应留空/未判。局部比较 A02 当前还需语义修订。

**哪些能算但不能作相应物理解释：** 噪声或 beat phase 的 GPA 应变；
带外被滤掉后得到的“零应变”；近重复坐标的 held-out pass；有限候选里的一项胜出；
实空间 FFT 与运动学模拟的几何相容；单一投影孪晶迹线。它们分别不能证明真实应变、
不存在应变、独立验证、唯一物相、实验衍射强度一致或三维孪晶/界面成立。
