      使用说明
      
  
      
    
      直接核对数值：打开图像 → 选择区域并统计，或绘制线段并测量 → 回查已有结果 → 保存工作区。无需先写研究问题或解释。主动组织研究：随时“记录研究问题”，需要解释时再用已有统计整理提议。FFT、峰位与周期测量按问题需要使用；原始文件只读。
      
    
      本说明可随时打开、关闭或按 Esc 退出；这些动作不清空草稿、不改变选区、不提交科学计算。Tab 移动焦点，Enter 操作按钮。
      
    
      1. 打开图像、选择帧与核对标定
      
      独立桌面可用顶部“打开图像…”：先选只读原图，再选保存分析结果的工作区目录；也可用原生菜单或 Ctrl/Cmd+O。已有分析用“打开分析工作区…”。开发机入口为 npm run desktop；仍需安装固定桌面运行时并指定科研 Python。浏览器入口仍可用 npm run inspect -- --source 原图绝对路径 --workspace 工作区绝对路径 --python Python绝对路径。源码先运行 npm ci、npm run build。
      
      
      TIFF 的“帧”从 1 开始。DM 多数据集、复数分量和高维平面须用明确启动参数选择，不猜缩略图、层深或轴意义。未知物理标定可先在像素域观察，不能凭空填入 nm；文件标定也不等于独立校准验证。
      图中印有已知标尺时，用“测量线”（L）沿标尺两端画线，再点线段操作中的“用已知长度定标”。填写标尺长度和单位，明确确认相同、正向 X/Y 像素尺寸假设，再“应用新标定”；Ctrl+S 保存工作区。单条线不能验证拉伸或分别求 X/Y。非等比例或带方向的现有标定请用“设置 → 补充／修订 XY 标定”。端点、已知长度、单位和手工来源随新版本保留；旧结果继续引用原标定，不会被改写。取消不改变选区或计算。
      
    
      
    
      2. ROI、峰位、测量线与移动图像
      
      默认“选择”（V）。左工具栏“ROI”（R）画完回到“选择”（V）；等待位置记录读回后再添加下一处。点击框的内部或边框选择，拖内部移动，拖八个控制点缩放；很小的 ROI 可先放大。重叠时在画布右键列出该位置的 ROI；悬停高亮、点击选择。也可点击 ROI 标签或在“对象属性 → 当前标注”中选择；普通点击保持最上层优先，选中控制点优先。列表选择不修改科学数据。
      
      
      “删除 ROI”或画布获得焦点后的 Delete 只撤回明确选中的 ROI。无选择不会全删，文字输入框里的 Delete/Backspace 只编辑文字。画布焦点下 Ctrl+Z 撤销一次手势，Ctrl+Shift+Z 重做；文本焦点下保留文本撤销。Esc 取消未完成手势；旧 FFT 输入和历史测量不会因此删除。
      
      
      “平移”（H）或空格拖动移动视野，滚轮缩放；“适应画布”（F）只调整相机。Shift/Ctrl 可约束新框和新测量线。临时矩形可直接 FFT，不要求先保存观察或填写理由。
      
      
      “对象属性”只展示当前选择相关的内容：ROI 的位置与说明预览，或峰／线段的测量与标定。名称在主要属性中编辑，颜色与状态在“标注颜色与状态”中展开；说明仍在“观察与证据”中编辑。“显示与高级设置”提供出图、标签、图层与解释修订。展开、收起这些区域不会替你保存或计算。
      
    
      
    
      3. 工作编辑与保存工作区
      
      位置修订会即时记录不可变工作版本，但不等于你已“保存工作区”。标注文字、颜色和标签在字段编辑期间保留本地草稿；“应用标注修改”可立即应用或明确重试，“保存工作区”会先应用并核对。拖动结束按现有规则记录工作编辑。Gamma／范围先本地预览，“应用显示”才把该配方应用为工作版本；即时记录的执行版本仍保留，但不等于明确保存分析。“保存工作区”或 Ctrl+S 保存同一源帧的整个分析：各 ROI、理由、标注样式、显示配方与明确采用结果，包括其他窗口停放的工作编辑。只有发布并读回保存点后才提示已保存；保存期间的新编辑仍显示未保存。
      
      
      相机缩放、平铺和面板开合是显示偏好，不因每次平移提示未保存。保存不会覆盖原 TIFF/DM 文件；“导出科学数据”导出也不等于保存分析。
      
      
      “应用当前 ROI 观察”打开观察面板；“应用 ROI 观察”记录这处的位置与理由，并保留对象、标记、标定与交接来源。提交中、对象已生成但交接核对中、读回完成是不同状态；等待校验，不反复点击。空理由不妨碍临时 ROI 做 FFT，也不自动变成物相结论。
      
    
      
    
      4. FFT、峰修订与测量
      
      在空间图上选择矩形后点击“FFT”。选中已有 ROI 后，“属性 → 关联结果”只读核对已有 FFT，可直接“查看 FFT”；几何修改后的旧结果会标为历史，不当作新位置的结果。关联读取失败可“重新读取关联”，只重读已有记录，不计算 FFT。“显示与高级设置 → FFT 选项”提供“FFT 窗函数”和“FFT 前去均值”。频域选择不会被当作新的空间 ROI 重算。
      
      
      用左侧“测量线”（L）画线，再点图下“测量长度”。在 FFT 用“峰位”点选，再点“测量周期”；频域两端线段使用“测量倒易距离”，不自动把任意两点当成 DC 到晶格峰。“数据结果”先显示名称、测得量、单位、来源 FFT 和当前／历史状态；“详细证据”查看原精度、标定、网格与原请求。尚无结果与筛选隐藏历史分别提示；后者可点“显示历史结果”直接展开。主动展开后后台读回不会反复收起。已有绑定测量的峰位修改保留原有条件自动重测，追加新测量并关联旧版本；没有绑定测量时仍需明确使用对应的测量操作。失败先查询原请求，不把旧数值贴到新峰上。
      
      
      拖科学标记改变锚点；拖文字只调整标签排版。数值算出、测量可靠性、物理解释分别表达，候选峰不是自动认证的真实反射。
      
    
      
    
      5. 返回空间图与窗口比较
      
      “返回空间观察”打开该 FFT 的准确历史空间输入，恢复其 ROI、理由和标定，不重算 FFT。刷新或重开后不保证保留这条浏览序列；保存的科学对象与窗口引用单独恢复。它与“查看最新 ROI”不同：后者打开后来的工作版本。缺少可核对来源时按钮说明原因，不从 FFT 整数边界猜原浮点框。
      
      
      图像上方一栏提供“← 返回”“前进 →”与当前图像类型。类型文字不是保存按钮，也不代表已经明确保存工作区。“分析历史”收纳已有结果和对象导航：“完整频谱”只恢复频域全图，“原图”打开已知全帧视图；若显示“全帧（新显示）”，则按当前标定创建新显示，不冒充旧观察。左侧“适应画布”只改相机，“视野”菜单另有同一操作与“专注图像”。
      
      
      当前 FFT 可从图下“原图与 FFT 对照”或“属性 → 关联结果”整理现有窗口并适应图像，只使用可核对的准确历史输入，不重算。来源需要先读回时仍经过原有版本与草稿检查；读回期间的新操作会阻止继续整理。旧输入显示它自己的原浮点 ROI，金色“FFT 计算区域”是向外取整后的实际支持范围，两者不一定完全重合。新工作区的首个 FFT 只在来源相机已核对、窗口足够宽且没有新布局意图时自动并排；恢复、普通切窗与后台刷新不重新适应全部窗口。
      同帧最多五个可见窗口。“窗口”菜单集中布局与窗口列表：“平铺并适应全部”明确平铺并调整各窗相机以看全图；“平铺窗口（保留缩放）”只改布局，用于保留缩放的对照；“单图编辑”保留其他窗口引用。点击非活动图像会置顶并经过保护切换编辑目标，第一次点击只激活；只有“当前编辑”接收科学工具。正常切窗停放工作编辑，不要求每次明确保存或放弃。正在执行或结果未知时须先核对原请求。
      
      
      窄窗口的属性／观察栏覆盖部分图像，不挤窄顶部操作和结果区；收起侧栏即可露出完整图宽，保留缩放与选区。选择“分析历史”或“窗口”中的操作后菜单会收起；点击菜单外或按 Escape 也可收起菜单，不清除选区或草稿。
      
      
      “关闭”或“关闭显示”只关闭子窗显示，保留工作编辑和科学历史；“窗口”菜单可“重新打开”。全部显示关闭后也可重新打开。新结果遇到可见窗口满额时等待查看，先关闭一个显示，再“查看保存结果”，不要重算。
      
    
      
    
      6. 人机接续与三个 ROI 对照
      
      要围绕某个空间 ROI 提问，选择矩形后点击“查看选区并提问”：先建立该选区的保存查看图，再在本地问题区明确应用问题；旧问题不会自动改写，统计与模型不会自动执行。已记录问题可“回到提问来源，查看同帧统计”，使用原有统计历史检查准确输入、ROI 和原请求；同帧结果不自动成为问题证据。
      无需 AI 也可完成日常分析。“Agent”菜单收纳两种交接：“准备研究交接提示”核对当前来源与多 ROI 关系并生成可复制提示；“记录当前选区供交接”只记录当前科学坐标，二者都不会自动唤醒模型。专用公开合成样例还提供“Codex 统计问答”，只接收问题与白名单统计，不发送图片，发送前另行确认范围。交接对话框可点击“复制继续提示”。
      
      
      “检查 Agent 结果”只读取外部结果；看到待接纳提示后明确点击“查看保存结果”，不自动覆盖本地草稿。CLI 可读取明确保存版本与稳定 ROI ID，查找输入、处理范围、配方和标定均吻合的 FFT，只在明确请求时补算缺项。它不需要操作浏览器按钮，也不读取含糊的 GUI 临时 ROI；临时工作须先明确冻结或交接。
      
      
      “ROI 对照结果”查看 CLI 的带来源报告，分别显示周期、图像坐标中的倒易矢量方向和未决项；该方向不等于晶体学取向。缺少测量点保持未知。查看报告不改变图像；“纳入工作分析”后仍需“保存工作区”。旧来源报告可作历史查看，不覆盖新编辑。“区域 1／2／3”仅表示本报告顺序，完整记录可展开“选区与来源”“计算来源”和“完整不确定性”核对。
      
    
      
    
      7. 退出、保存失败与错误恢复
      
      独立桌面关闭工作区或退出时，有修改才询问“保存／不保存／取消”。取消保留工作；保存失败或出现新编辑则保持打开。“不保存”回到上个明确保存点，但已经执行的 FFT、其真实输入和旧测量仍在历史，不自动纳入保存分析。“分析历史 → 探索执行历史”（桌面“窗口”菜单也有同名入口）可查看已保存的原输入或 FFT；旧记录缺少原浮点输入时保持未知。
      
      
      正常重开读取明确保存版本；崩溃留下的草稿需点击“恢复未保存编辑”单独恢复，不冒充已保存。有恢复副本时，先恢复它，或明确点击“放弃未保存恢复副本”，再编辑和执行分析，避免再次中断覆盖旧草稿；仍可缩放、平移、调整窗口及保存当前保存版。放弃副本不删除已执行的科学记录。故意丢弃的工作不会下次无提示复活。浏览器页签关闭仅有浏览器通用提醒，不能替代桌面三选项。
      
      
      保存响应未知用“查询原保存”；科学请求未知在“显示与高级设置 → 诊断与原请求恢复”点击“查询上次原请求”。始终保留原请求身份；不换 ID 自动重放。409 接纳拒绝不能单独证明后端没有生成对象。只有本批历史 ROI 修改获得严格匹配的“科学派发前拒绝”证明时，才明确显示未创建本批科学请求：临时选区和草稿保留，可明确撤回本地草稿或不保存退出；“应用标注修改”／“保存工作区”才会显式尝试，不自动重发。它不能解除其他未决原请求；本地草稿处理后可“查看最新 ROI”再编辑。
      
      
      部分旧保存版未记录已能核对的来源帧时，图像上方会出现“重新核对来源”。该操作只核对当前准确保存对象的既有来源和资产，不创建预览或重算 FFT；成功后须“保存工作区”另建保存点，旧保存点不变。响应未确认时按钮改为“查询本次来源核对”，只查该原请求。若提示来源链超出当前核对范围，保持只读并保留原记录；能返回空间图不代表所有测量或执行输入都已取得来源资格。
      
      
      需要持久来源证明时，在“显示与高级设置 → 诊断与原请求恢复”明确“核对并记录来源证明”；已有完成 FFT 的“记录输入证明”在“探索执行历史”对应行。它们只核对并追加证明，不生成预览、不重算 FFT 或测量。证明已记录、采用为工作引用、Ctrl+S 明确保存是三个步骤：记录完成不会自动采用；采用前再次核对准确对象、完整依赖、窗口和草稿。回溯输入证明保留原执行资格，不能冒充原计算前的证明。未知响应只用“查询本次证明原请求”，不换 ID 重发；若本 helper 的准确持久收据证明尚未派发，才解除这一次本地等待。读取会显示撤回、损坏或不兼容等失效原因；失效证明不会授予来源资格。原证明不自动覆盖新增对象版本，须明确核对当前准确根。来源证明失效时科学写入被阻止；可保留本地草稿记录新的当前对象证明，再在“采用方式”明确选中旧引用并替换。GUI 替换仅支持新证明绑定当前准确空间对象和同一工作帧；FFT 输入证明绑定原始 FFT，与当前显示对象不同，不能冒充该显示对象的替换证明。采用空间来源证明也不声称修复了旧 FFT 输入证明。替换只改工作引用，保持字段、坐标和相机，不自动重发被拒编辑；新证明不声称包含尚未应用的草稿。真正未决科学请求或未决保存仍须先核对。若旧保存点自身依赖失效证明，“不保存”恢复可被拒绝；保留原记录，选择修复并另存或取消。新保存点只保存准确证明引用；不保存可丢弃工作引用，原证明、旧来源和原执行记录仍保留。已保存的证明引用在重开时重新完整核对，无法核对时保留原记录并拒绝操作性恢复。
      
      
      只读保存图像加载失败会保留上一已核对画面并说明状态，可“重试只读图像”，不创建新预览或 FFT。观察理由最多 1000 个 UTF-16 单位，超限保留原稿而不截断。未决任务、工作区冲突或旧格式资格不足时按原因处理，不放宽网格、来源或所有权保护。
      
    
      
    
      8. 如何阅读科学结果
      分别看计算是否完成、测量可靠性和不确定性、候选解释的条件。像素周期差异不自动等于应变，有限相容不等于唯一物相、晶向、孪晶或缺陷确认。材料背景是研究者提供的证据，不用来反造比例尺。原始数据、标定来源和历史结果继续保留。
      
    
      9. 窄窗口与面板
      “观察与证据”“对象属性”和“显示与高级设置”可收起。界面宽度不超过 850 px 时，属性／观察栏作为抽屉覆盖部分图像，顶部操作和结果区使用完整宽度。可点击面板的“×”或对应工具收起，露出完整图宽；字段内容、缩放与选区保留，需要调整视野时再点“适应画布”。保存工作区在顶部，选区操作在图像下方，面板内容可滚动。“对象属性”只显示当前选择相关的字段；标签与图层在“显示与高级设置 → 标签与图层”中。尺寸改变不自动改科学选区。各图已记录的侧栏、设置分组和结果区开合会与相机一起恢复，作为显示偏好，不增加未保存的科学修改；旧记录没有这项偏好时使用明确的默认显示。
