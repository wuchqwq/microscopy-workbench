      使用说明
      
  
      
    
      从多个 ROI 开始：点“添加 ROI”（R）框选，松手保存位置并回到选择工具；每次等保存读回完成，再点“添加 ROI”画下一处。点击框内移动，拖八个控制点调整大小；小框可先放大。选中 ROI 后点“删除 ROI”，或点击画布使其获得焦点后按 Delete；仅撤回所选框，历史保留，可用“撤销”恢复。文字输入框内的删除键只编辑文字。FFT 仅在明确点击时计算。需要说明观察时选择对应 ROI、填写理由并保存。快速探索也可在选择工具的空白处拖出临时框，直接 FFT，不必保存。
      
    
      这份说明只帮助阅读和操作当前工作台。打开、关闭或按 Esc 退出，不提交计算，也不丢弃草稿、选区或相机位置。Tab 可切换控件，Enter 可操作按钮或展开条目。
      
    
      1. 打开图像、选择帧和核对标定
      
      图像由本地启动器或已连接的 Agent 打开；当前页面没有文件选择按钮。首次启动用 npm run inspect -- --source 绝对图像路径 --workspace 新工作区绝对路径 --python 独立Python绝对路径。源码仓库先运行 npm ci 和 npm run build。
      
      
      TIFF 的“帧”输入框从 1 开始，按 Enter 或用前后箭头切换。DM 数据集或多维平面在启动时明确选择：--dataset、--plane-axes 与 --plane-indices；不把深度自动解释成时间帧。
      
      
      “观察与证据”和“对象属性”显示来源及当前标定。未知物理标尺时仍可做像素域观察；频率保留 cycles/px，不凭空给出 nm 间距。补充标定须在“显示与高级设置”中填写实际来源。
      
    
      
    
      2. ROI、峰位、测量线与移动图像
      
      “添加 ROI”（R）在空间图拖出矩形并保存位置，理由留空表示尚未说明观察，不确认物相。“选择”（V）可从内部选中任一已保存 ROI 并移动；四角和四边控制点可缩放，坐标限制在准确源面板内。临时矩形也可移动或缩放，但不会自动写入保存对象。FFT 图上的 ROI 工具只建立临时频域框。
      
      
      “平移”（H）或按住空格拖动移动视野，滚轮缩放；“适应画布”（F）只调整相机。Shift / Ctrl 可约束新 ROI 为源像素对齐正方形、新线段为水平或垂直，不约束已有标记的修订。
      
      
      “添加 ROI”完成保存和读回后，可继续添加 ROI 1、2、3；“选择／调整 ROI”让 FFT 和统计作用于当前选中的框。“临时矩形（不保存）”仅是当前操作位置。“查看选区”打开局部视图；“统计当前 ROI”读取该区域的科学数组统计。
      
    
      
    
      3. 保存观察与理解保存状态
      
      在空间图框选后，点“保存当前 ROI 观察”，写清看到了什么或为什么选择这里，再点“保存 ROI 观察”。已有观察可“更新这条观察说明”；列表中的位置、理由和稳定观察 ID 一起保留。
      
      
      正在提交观察
      请求尚在等待，不能据此认定保存成功；不要连续重按。
      观察已保存 · 正在核对交接
      保存对象已返回，身份、锚点和交接状态仍在读回校验。
      ROI 观察已保存并读回可接续
      本次保存与当前交接已核对，可以继续；不代表物理解释已确认。
      本地草稿 / 说明尚未保存
      仍有未提交的说明、标记或显示修改。保存中的观察计数可能暂未翻转，请看流程结束后的状态。
      
      
      仅画选区不会自动保存观察理由。原始图像、旧观察和历史修订保留；“撤回全部本地草稿”须由你明确选择。
      
    
      
    
      4. FFT、峰修订与测量
      
      先在空间图选择矩形，再点“FFT”。窗函数与去均值选项在“显示与高级设置”里的“FFT 选项”。已有 FFT 上的频域选区不能再次当空间 ROI 计算 FFT。
      
      
      频域中用“峰位”点选，再点底部“测量”；空间图用测量线测两点距离。“数据结果”的“测量”页查看保存值、标定和来源。GUI 不提供通用自动找峰或物相认证按钮；Agent 可通过现有工具提出待研究者检查的峰或候选。
      
      
      用“选择”拖动已有科学标记，松手保存新修订；拖动文字只改标签排版。已有绑定测量或数值标签时界面会尝试重测；其他保存标记修订后可重新点“测量”。已有旧测量时，新测量链接旧测量。旧记录仍保留；重测失败时先恢复原请求，不把旧数值当作新峰的结果。
      
    
      
    
      5. 返回空间图：哪些按钮返回什么
      
      从空间保存视图执行“FFT”后，“返回空间观察”打开此次转换前的准确保存视图，保留其 ROI、理由、标定和显示范围，不重算 FFT。注册工作区正常关闭并重开后会重新核对该引用；这不恢复完整浏览历史。旧记录缺少引用、来源不匹配或首次由 Agent 直接打开的 FFT 没有合格引用时，按钮不可用并说明原因，不猜测原观察。返回前须保存或撤销草稿并处理待查看结果。
      
      
      目标暂时无法读回时，当前 FFT 与草稿保留。恢复来源后正常关闭并重开同一工作区，重新核对候选引用；未通过核对前不能返回，也不会自动生成替代图。原计算请求尚未确认时，先查询原请求。
      
      
      “完整频谱”只恢复 FFT 自己的完整频域窗口，不返回空间图。“← 返回”和“前进 →”打开本次浏览器会话已经查看过的保存视图，不重算 FFT；刷新或重开后不保证保留这条浏览序列。
      
      
      导航的“原图”打开同帧已知的全帧保存视图；没有该显示配方时按钮叫“全帧（新显示）”，按当前标定新建源帧预览。源帧所属域以来源记录为准；导入的倒空间原数组不因此变成空间图。新显示不会恢复先前观察视图的 ROI 理由、旧标定和显示范围。
      
      
      晶体比较证据中有原观察引用时，还会出现“返回观察原图”。没有合格引用或按钮不可用时，请保留当前工作，请 Agent 读取来源并呈现对应的保存空间视图；不要把任意数组 ID 当作保存预览。返回前先处理草稿。
      
    
      
    
      6. 自己操作与交给 Agent 接续
      
      你可以先操作 GUI 再请 AI 继续；也可以接管 Agent 已打开的同一 Panel。完成保存并核对后，点“交给 Agent 继续”，再点“复制继续提示”，粘贴给已连接的 Agent。当前 GUI 没有内嵌聊天，不会自动唤醒模型。
      
      
      多 ROI 交接同时列出已保存的各个框、未填写的理由，以及各 FFT 生成时的区域和当前 ROI 的关系。你可以停在 FFT 上交接，空间观察从准确来源另行读取；改过位置的框不会被写成旧 FFT 的输入。引用不可用或状态改变时保留未知，先重新读取，不自动补算。
      
      
      底部“AI 交接”只交接当前选择；它不代替保存正式 ROI 观察。Agent 应重新读当前 Panel、确认草稿和来源后再处理，不沿用已过时的截图或标定。
      
      
      出现“有新结果等待查看”时，可继续核对当前工作，再明确点“查看保存结果”。只有真有草稿才显示“放弃草稿，查看保存结果”；先保存、撤销或明确放弃，不能让晚到结果覆盖新编辑。
      
    
      
    
      7. 出错、未知结果与正常恢复
      
      保存失败或请求结果未知时，保留原 request ID 和草稿。在“显示与高级设置”→“诊断与原请求恢复”中使用“查询上次原请求”，或请 Agent 用同一个 ID 查询。不要换 ID、换入口或再次计算来猜测原请求结果。
      
      
      观察说明超限时按提示缩短再保存，原草稿不会被截断；上限为 1000 个 UTF-16 单位，部分符号占两位。遇到 PREVIEW_REQUIRED，先确认或恢复原预览请求，再打开已保存预览。活跃 helper 上拒绝 resume 时继续使用当前 Panel，不重复启动。
      
      
      “检查 Agent 结果”重新读取当前状态，不表示必须接纳待查看结果。服务端已保存、Panel 允许接纳、浏览器已显示是三个不同状态；409 接纳拒绝不能单独证明后端没有生成对象。
      
      
      关闭前确认保存和读回已完成，再在启动终端按 Ctrl+C 正常停止 helper。重开时使用相同的 --workspace 与 --python，首次的 --source 可省略；启动器恢复可验证的保存对象和引用，不自动重算 FFT。若还有草稿，按恢复提示明确处理；关闭浏览器页签不等于停止终端 helper。
      
    
      
    
      8. 如何阅读科学结果
      
      分别看数值是否已计算、测量可靠性有哪些依据或未知项、候选解释在什么条件下相容。像素周期差异不自动等于材料应变，有限候选相容不等于唯一物相或孪晶确认。原始数据与来源记录继续保留，研究者决定下一步。
      
    
      
    
      9. 窄窗口与面板
      “观察与证据”和“对象属性”使用现有侧栏，窄窗口中以抽屉覆盖图像区域；导航与底部选区操作保留在外侧。面板内容可滚动，保存按钮在“保存观察”内；顶部“×”可收起面板，草稿仍保留。窗口改变大小时不会自动移动相机，视野不合适可点“适应画布”。
      
    
      10. 多处 ROI 与图像窗口比较
      
      同一源帧最多保留五个图像窗口，可分别查看两处 ROI 的局部图和 FFT。点击窗口内容或边框可置顶；拖动标题移动窗口，拖右下角调整大小。“平铺窗口”把它们排列比较，“单图编辑”只显示当前图，其余窗口引用仍保留。置顶只改变遮挡顺序；要修改另一张图，点击它的“编辑此图”。
      “返回空间观察”仍打开该 FFT 的准确历史输入；后来保存的 ROI 不会被改写。历史来源图显示“查看最新 ROI”时，先明确打开最新保存视图再新增或调整 ROI；历史图仍可使用临时选区探索，不会自动跳转。
      
      
      只有标为“当前编辑”的窗口接收科学工具操作。其他窗口标为“只读对照”，可以滚轮缩放、拖动查看或点“适应”；这些操作不会切换编辑目标。“编辑此图”明确切换操作目标，保留该窗已经核对的相机和选区。新 GUI FFT 的输入浮点框单独记录；旧记录缺失时不从整数边界猜测。
      
      
      “关闭”或“窗口列表”中的“关闭显示”只卸载只读窗口，保存对象、测量和历史仍保留。当前编辑窗口不能直接关闭。窗口已满时，新结果已保存但等待显示；先关闭一个只读窗口，再点“查看保存结果”，不要重复计算。窄窗口默认显示当前图，仍可用窗口列表关闭不需要的只读显示。
      
      
      每份 FFT 的计算窗口和来源单独保留；并排不表示标定一致或物理解释已确认。“出图与标注样式”和数据结果默认收起，需要时展开。
